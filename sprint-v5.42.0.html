5. Sprint Post-Mortem: What Worked vs. What Didn’t (A477 & Obsr)

Candid synthesis by the Project Manager, Architect (A477), Integrator (TC-Lane-INT), and Sprint Observer (TC-Lane-Obsr) of what succeeded and the concrete process/tooling bottlenecks uncovered during v5.42.0.

✅ What Worked Exceptionally Well (Keep & Codify)

  • 1. Shared-File Hotspot Separation Matrix + Unified Schema v71 in W1-B (PR #2651) Shipped 9 Launch-Readiness Issues with 0 Merge Conflicts Nine of the ten Milestone #27 issues modified the same five launch-readiness modules (lib/launch-unready.js, lib/launch-kickoff.js, lib/launch-bootstrap.js, lib/routes/launch-recovery.js, and public/ui.js), and three issues needed SQLite schema additions. Partitioning those hotspot files across Wave 1 and Wave 2 while consolidating all DDL into a single unified Schema v71 migration inside W1-B (#2651) achieved 0 same-wave file overlaps and 0.0m conflict resolution time across all 8 PRs.
  • 2. Early Wave 2 Pre-Warm on Freed Lanes (TC-Lane-A & TC-Lane-D) Opened W2-A (#2657) and W2-B (#2656) Just 11.3m–13.5m After Wave 1 Completed Because W1-D (#2653) merged in 54.7m and W1-A (#2652) merged in 105.0m while W1-C and W1-B were still completing CI and ancestor syncs, TC-Lane-D and TC-Lane-A pre-analyzed their Wave 2 cars ahead of time. Once W1-B (#2651) landed at 02:06Z, PR #2656 and PR #2657 opened in just 11.3m and 13.5m.
  • 3. Dual Exact-Head R-Gate + A-Gate Caught 8 Real Correctness & Documentation Defects Pre-Merge (Including W4-REL CHANGELOG.md Precision) TC-Lane-PRR-A, TC-Lane-PRR-B, and TC-Lane-Arc intercepted 8 concrete bugs before merge — including an unguarded renderStartupReadinessBadge regex in test/engine-error-ui.test.js:200 on W2-B (#2656) R5 and two inaccurate release-note claims in W4-REL (#2659) R1 (clarifying that clean not-applicable launches need no readyAt and ended sessions have no Clear action, fixed in 7b162c75).
  • 4. P0 Single-Turn Plan+Build Achieved 30.4m–36.3m Builds Across 3 of 4 Wave 1 Cars with 0 AskUserQuestion Stalls W1-B (#2651) built in 30.4m, W1-A (#2652) in 33.6m, and W1-D (#2653) in 36.3m — all in a single continuous turn without intermediate /clear resets or interactive TUI freezes.

⚠️ What Didn’t Work & Proven Fixes for v5.43.0

  • 1. Literal Rule #282 Current-main Containment Overrode P12 Disjoint Merge Pipelining, Forcing 4 Redundant Ancestor Syncs & Re-Review Loops (Finding W1-F1_v542) Even though Charter A477 guaranteed 0 file overlap between W1-A, W1-B, W1-C, and W1-D, TC-Lane-INT enforced a strict reading of Rule #282 requiring each PR’s head SHA to contain the latest origin/main commit before guard-merging. Consequently, W1-B (#2651) — which built in just 30.4m — had to merge origin/main twice and re-run 12m CI + R-Gate + A-Gate, stretching its total time to 178.2m (2h 58m). Fix for v5.43.0: Clarify in the co-signed Sprint Charter that wave-base containment + mergeable: MERGEABLE + 0 file overlap satisfies Rule #282 for sibling PRs in the same wave so TC-Lane-INT merges them back-to-back without ancestor rebases.
  • 2. Authorizing a [NEW] Test File Without test/tiers.json & .testament.toml Caused a Preventable R1 CI Failure on W1-A (PR #2652, Finding W1-F2_v542) W1-A (#2652) opened in 33.6m and passed both R-Gate and A-Gate on R1 head 96885e45, but failed 6 manifest assertions in CI run 40603856117 because Charter A477 authorized test/launch-pane-writer.test.js [NEW] without authorizing the shared manifest files test/tiers.json and .testament.toml. TC-Lane-A fixed it in R2 (07b4ed82) by folding the new tests into test/launch-unready.test.js. Fix for v5.43.0: Fold new unit tests into existing authorized test/*.test.js files whenever multiple cars run in parallel, or explicitly authorize test/tiers.json + .testament.toml in exactly one car per wave and run node scripts/test-tiers.js --check before opening the PR.
  • 3. Unchanged Linux CI Runner Flakes in test/tmux-tcc.test.js (osascript: not found) & test/tailnet-cutover.test.js IPC Cost 4 CI Reruns (Finding W1-F3_v542) Unchanged tests caused 4 non-diff CI failures across W1-B (#2651) run 40614970375 (attempt 1: test/tailnet-cutover.test.js Node test-runner IPC deserialization error; attempt 2: test/tmux-tcc.test.js server exit) and main runs 40618948445 and 40623894487 (test/tmux-tcc.test.js invoking macOS osascript on Linux). Fix for v5.43.0: Schedule W1-F3_v542 directly in Wave 1 of v5.43.0 to guard macOS-only osascript calls in test/tmux-tcc.test.js and isolate subtest IPC in test/tailnet-cutover.test.js.
  • 4. Unscoped Companion Test Files Required Mid-Wave Scope Amendments & 6 Rounds on W2-B (PR #2656) Modifying public/ui.js and lib/medusa-wake.js in W2-B (#2656) interacted with legacy stubbed assertions in test/medusa-wake-exchange-proof.test.js (causing a 27m CI hang on R4 run 40624910675) and source-regex checks in test/engine-error-ui.test.js:200 (caught by A-Gate on R5). Fix for v5.43.0: Run grep -rn across test/ for every modified function name in public/ui.js and lib/medusa-wake.js during charter drafting so all companion test files are included in the initial car scope.
