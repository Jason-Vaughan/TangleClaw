- Engine Usage provider probes (`claude`/`codex`/`antigravity`) no longer
  lose a valid reading on a transient refresh failure (#3208): a probe that
  finds nothing now preserves the previous reading's percentages, resets,
  and sub-tiers, marking it `refreshDegraded: true` with `lastRefreshError`
  naming why, rather than overwriting it with nulls. A successful refresh
  now also records `lastSuccessObservedAt`. `refreshAllUsageProbes` uses
  `Promise.allSettled`, so one provider's unexpected failure can no longer
  take the other providers' already-successful readings down with it.
