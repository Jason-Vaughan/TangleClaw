- Startup-rules receipt watcher: `lib/rule-receipt-redelivery.js` watches
  `rules-hook` deliveries that stay `written` after a session has been
  active past a grace window, distinguishes a hook that never ran from one
  whose receipt POST alone failed (a sandboxed engine with loopback blocked,
  #1150), and, only when nothing local explains the silence, re-delivers the
  rules a bounded number of times through a caller-supplied open channel —
  surfacing an explicit, named escalation once attempts are exhausted
  unconfirmed, so no session silently keeps running with undelivered rules
  (#1176).
