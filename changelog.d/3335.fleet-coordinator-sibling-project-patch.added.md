- A verified Fleet Coordinator (`fleetCoordinator: true` with an active `project-manager`
  coordinator role) may now `PATCH /api/projects/:name` for a sibling project that either
  shares its project group or sits inside its own `<Prefix>-*` fleet namespace (e.g. a
  `TiLT-PM` coordinator configuring `TiLT-Arc`, `TiLT-Lane-*`, `TiLT-PRR-*`, `TiLT-INT` or
  `TiLT-Obsr`), while a cross-fleet project outside both stays denied and a non-coordinator
  project member's own-project-only restriction is unchanged
  (`lib/shared-docs-access.js#canChangeProject`, #3335).
