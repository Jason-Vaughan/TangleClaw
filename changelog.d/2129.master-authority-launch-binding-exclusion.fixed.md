- `POST /api/master/authority` now refuses any caller carrying a launch-binding header (project,
  role, or launch id) before proving operator identity — the same exclusion
  `PATCH /api/config`'s equivalent `accessLevel` transition already applies. On an open install,
  the generic operator check alone reads any dashboard- or browser-shaped request as the
  operator, so a project session could have forged that shape (plus a page token fetched from
  its own `GET /api/auth/me`) to grant the Project Master write authority over the fleet API to
  itself. Both routes now share one implementation
  (`lib/routes/_callers.js#_requireOperatorWriteExcludingLaunchBinding`) (#2129).
