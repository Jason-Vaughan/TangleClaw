- `lib/store.js` now narrows the TangleClaw data directory to `0700` on every boot (not only on
  create), and narrows SQLite's `-journal`/`-wal`/`-shm` siblings to `0600` when they exist beside
  `tangleclaw.db`. The directory now owns the permission posture instead of relying on per-file
  chmod alone — a `0755` directory previously let every local account list it and open anything
  inside whose own mode permitted (#1421).
