- Fixed four v6 Fleet Shell chat/workspace regressions and staggered the
  Start Offline/Start Fleet batch launcher: `loadWorkspacePanel` no longer
  fires an unscoped Sprint & Cars/Kaizen & Reports read while the active
  project is still resolving, and drops a stale per-mode response via a
  monotonic generation counter; an engine coalescing two queued user
  messages under one `> ` prompt echo now shows the second as its own
  chat turn instead of silently dropping it; a non-backticked JS ternary
  or URL query-param token in a declarative reply line no longer gets
  misread as an open "Waiting on: YOU" question, and an earlier
  multi-paragraph reply's own superseded paragraph no longer resurfaces
  across a second Medusa wake; a wrapped-line URL glue no longer swallows
  a following sentence or stray parenthesis onto the URL, and a stray
  unmatched `(` is truncated out of a rendered link instead of being
  included in it; and launching 10+ fleet members no longer fires every
  tmux/CLI/hook startup in the same instant, which was bouncing several
  lanes `Starting -> Off -> Starting` under concurrent load (#3355, #3352).
  Also fixed three Codex TUI chrome lines leaking into the chat stream as
  fake bubbles: a completed-turn timing recap with a bare clock time
  instead of the word "done", Codex's own non-empty input-box placeholder
  text being misread as the operator speaking, and Codex's middle-dot
  status bar footer.
