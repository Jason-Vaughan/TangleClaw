- A fleet member can now be renamed from the v6 chat (#3071): a `✎` button in the chat header opens an inline form (Save, Cancel or Escape), and the new name goes through the same project rename the Classic settings use. The header, the sidebar tree and the delegate picker show the new name at once, and any warning the rename raises (for example about scripts that name the old folder) is shown with it. A project with a live session cannot be renamed — the button is disabled and its tip says to stop the session first — and anything else the server refuses, such as a name already taken, is shown with the server's own reason.
