- A scoped `projectsDir` default for a scratch `TANGLECLAW_HOME` (#2604): `lib/scratch-home-defaults.js` resolves whether a server's base directory is the operator's canonical `<home>/.tangleclaw` or a scratch/temp override, and if scratch, scopes the default `projectsDir` inside it (`<TANGLECLAW_HOME>/projects`) instead of the operator's real `~/Projects` — so the Builder Role Overlay's mandated scratch-server browser check (`LANE_QUEUE.md` Rule #271.3) is actually isolated, not isolated-looking. This slice is the resolution primitive only; wiring `lib/store.js`'s own default is a later slice.
