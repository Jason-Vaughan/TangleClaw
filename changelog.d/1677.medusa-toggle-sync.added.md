- A reconciliation module for the PM Medusa toggles (#1677): `lib/medusa-toggle-sync.js` resolves each toggle's persisted value, its effective value (always the persisted one, never an optimistic runtime guess), and whether a live runtime signal drifts from it — so a transient per-session listener can no longer look like a persisted opt-in. This slice is the reconciliation primitive only; wiring a real caller (the settings-modal API route, the dashboard banner) through it is a later slice.
