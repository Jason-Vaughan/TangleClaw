- v6: a code-to-doc parity checker (`lib/v6/f2-code-doc-parity.js`) generates
  the `tc` verb, HTTP route, project-default and engine-profile reference
  tables from the code that defines them, and reports any drift from the
  marked table in each target doc as a line diff. It never rewrites a doc. A
  route registered with computed arguments, or a source it cannot read
  cleanly, fails the check instead of leaving a silently incomplete table.
  The CI step and the marked tables in the docs are separate, reviewed
  changes (#2998).
