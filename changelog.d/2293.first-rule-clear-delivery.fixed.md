- A project's first rule, approved after a launch that had none to deliver, now reaches a running session on its next `/clear` or compaction instead of waiting for the project's next launch — the refresh that rewrites a project's delivered rules files now registers the rules hook it needs (and any further hook a rule set outgrows) instead of only ever rewriting files a launch already wrote (#2293). Verified against the real `claude` CLI (v2.1.283): a hook added mid-session does fire on the running session's next `/clear`, not only at launch. An engine with no `SessionStart` hook mechanism (`codex`, `gemini`, `antigravity`, `aider`) still only gets the rule on its next launch, or immediately via `tc rules`.
