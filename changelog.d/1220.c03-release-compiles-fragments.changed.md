- A wrap that cuts a release now compiles every fragment under `changelog.d/`
  into `[Unreleased]` before deciding the bump level, and commits the promoted
  `CHANGELOG.md`, the bumped version file and the fragments' deletion as one
  commit. A refused fragment stops the cut, naming the file and its code. Every
  release file's prior bytes and index entry are recorded under
  `.tangleclaw/release-recovery/<run id>/` before the flush; any halt before the
  commit lands puts them back, and while a record remains no cut is made (#1220).
