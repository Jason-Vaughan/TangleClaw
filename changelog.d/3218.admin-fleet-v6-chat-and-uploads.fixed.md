- Fixed Admin Fleet (Admin-PM) file uploads being restricted to images only: the Master control bar's file picker no longer carries `accept="image/*"`, so standard documents (MD, TXT, JSON, PDF, logs) can be attached the same way V6 chat and Classic project upload already allow. Added a shared `tcSanitizeMasterAttachmentFilename` so a macOS screenshot name ("Screenshot 2026-11-22 at 9.15.00 PM.png") or any name with spaces or parentheses — previously rejected outright by `lib/secure-clipboard.js`'s safe-filename grammar — is sanitized before upload, with `-2`/`-3`/... dedup against names already used in the same batch. Added `tcBindMasterDropzone`, a shared iframe-safe drag-over dropzone overlay and clipboard-paste file intake for the Master panel, so dragging or pasting a file over the `ttyd` terminal view no longer gets swallowed by the iframe itself (#3218).
