- Added `lib/release-automation.js`: opt-in (`releaseAutomationEnabled: true`) release automation for TangleClaw-managed projects — resolves the project's version and changelog path the same way `version-bump` does, classifies the `origin` remote (GitHub vs. other vs. none), plans and applies a tag/GitHub-Release, and can generate a self-contained GitHub Actions workflow template for projects that would rather run their tagging on Actions (#721).
