- `lib/shared-docs.js` adds `ensureGroupSharedDir`: configuring or resolving a project group's `sharedDir` that does not yet exist on disk now validates path safety (a non-empty absolute path, never the filesystem root, no null bytes) and creates it (recursively) instead of throwing `ENOENT`, returning `{created: boolean}` so a caller can tell a fresh directory from a reused one (#1305). An existing directory is left untouched; a path that collides with an existing regular file fails closed with `SHARED_DIR_NOT_A_DIRECTORY`.
