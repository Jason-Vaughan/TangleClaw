- The `gh pr merge` role guard now recognizes multi-fleet Integrators and a standalone repo's own merge convention (#3110). `lib/merge-role-guard.js` previously resolved only `TC-Lane-INT` as an Integrator and allowed only `--merge` for everyone; it now also resolves any `<fleet>-INT` or `<fleet>-Lane-INT` lane (for example `TV-INT`), plus `TiLT-v2` and `Monad-1` by name, as Integrators, and lets `Monad-1` merge with `--squash` (its own repo convention) while every other fleet, including `TC-Lane-INT`, stays restricted to `--merge`. A new `allowedMergeMethods` option generalizes the same per-caller exception for any other repo's own convention.
