- `lib/server-info.js` resolves the background server's checkout root through a dedicated
  `TANGLECLAW_SERVER_ROOT` override when set, instead of always reading whatever checkout its own
  module files happen to sit in. `getServerInfo()` now also reports `checkoutCoupling`: whether
  the resolved root is itself a linked git worktree, or a primary checkout with active
  Builder/agent worktrees linked off it right now — so the server no longer silently inherits an
  active checkout's branch/freshness state as its own (#1672).
