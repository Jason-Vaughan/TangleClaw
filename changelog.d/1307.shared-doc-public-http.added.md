- `lib/shared-docs-http.js` adds a read-only public HTTP / MagicDNS shared-document link builder and responder: `buildSharedDocMagicDnsUrl` constructs the canonical shareable URL for a registered document, and `resolveSharedDocumentHttp` serves its content strictly confined to its own group's registered `sharedDir` -- resolving every symlink (`fs.realpathSync`) before confining, so neither a `..` path traversal nor a symlink planted after registration can escape it (#1307). Mounting an Express route for this is a tracked Slice 2 follow-up (Milestone #51).
