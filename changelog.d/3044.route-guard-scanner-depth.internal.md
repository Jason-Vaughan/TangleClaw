- The master release-qualification suite's route-guard check now holds every `/api/v6` handler to a closed-world grammar (#3044). The handler must be an inline arrow block, so an expression body or a function reference cannot borrow the next route's guard. The fail-closed caller check must be the handler's first statement, or follow only `const q = parseQuery(reqUrl(req).search);`, and must pass exactly `(req, res, '<action>')`. The previous scanner searched for a guard anywhere in the handler, and a guard on one branch (with or without braces) or in a callback, a body read, or a call in any spelling before or inside it could pass. Nothing can now run first: no body or property read, call, branch, block or callback. Mutation regressions cover each case. The malformed-fragment assertion is renamed to say what it checks.
