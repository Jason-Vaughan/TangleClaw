- Added `lib/fleet-sdlc-policy.js`: a configurable fleet SDLC policy
  validator, hierarchy resolver, and `evaluateCarAdmission` enforcement
  engine for fleet issue/roadmap admission (`issueBackend: "github" |
  "local" | "none"`, `requireRoadmapTriage`), so GitHub Issues + Roadmap
  triage enforcement applies to fleets that use it (like `TC-Lane`) without
  being imposed on fleets that don't. A real dispatch-admission caller (such
  as `lib/roadmap-admission.js`) consuming this contract is separate,
  already-scoped follow-up work, not part of this change (#3265).
