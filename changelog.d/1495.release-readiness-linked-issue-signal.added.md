- Added a `linked-issue-closed` release-readiness signal (`lib/release-readiness.js`'s `linkedIssueClosedSignal`): **included by default** in `gatherReleaseSignals` (set `includeLinkedIssue: false` to opt out), it discovers the issue a release is cutting for (an explicit issue number, the active build plan's `Issue:` line, or a commit's `Fixes #N`/`Closes #N`/`Resolves #N`) and judges it via a direct, timeout-bounded `gh issue view` call by default (or a caller-supplied lookup), reading `n/a` with nothing linked and `unknown` — never `pass` — whenever the state can't actually be read, including when `gh` or the network is unavailable (#1495, default-inclusion per Architect ruling A481-R5).
