- Clicking a project or fleet in the v6 Fleet View now opens a chat with that project's Designated Delegate instead of a read-only event list (#3047). The delegate is the project's `-PM` member by default (then `-Master`, then the first member with a live session), and can be changed from the chat header, which remembers the choice; clicking a single lane opens a direct chat with it, with a link back to the delegate. The chat shows who you are talking to and whether its session is active, idle or offline, the recorded conversation, and the session's live output (refreshed every 4 seconds). A message typed in the composer (Enter sends, Shift+Enter adds a line) is sent into the session and recorded in the conversation; if the server refuses it — a held lane, a session that is not ready, a running wrap — the chat shows the server's reason and keeps the text.
