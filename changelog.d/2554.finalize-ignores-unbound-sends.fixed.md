- `tc finalize` no longer refuses a lane with `EXCHANGES_OPEN` over a message whose send never bound a Hub id (`send_pending`/`send_unknown`). The lane could never read or acknowledge it, and `tc message owed` already left it out (#2554). The verified Project Master can now close the exchanges it sent, an orphaned `send_unknown` one included, through `POST /api/master/medusa/exchanges/<id>/close`. Anyone else's exchange still answers `403 NOT_INITIATOR`.
