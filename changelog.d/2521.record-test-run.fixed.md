- A full-suite record could no longer read green over a red it never saw (#2521). Prawduct's recorder counts only the cases beneath a top-level `<testsuite>`, and node:test's junit report also puts cases at the top level and inside an `<undefined name="root">` element: on the measured report it recorded 12,785 passed over a 21,997-case run with a deterministic failure among the cases it skipped. `node scripts/record-test-run.js` now runs the suite through `scripts/suite-evidence.js`, judges the raw report with `lib/test-results.js`, hands Prawduct a copy with every case beneath a top-level suite (`hoistToTopLevelSuites`, which refuses any shape it does not recognise and checks that no case, failure or skip was lost), and re-reads `.prawduct/.test-evidence.json`, refusing on any count that disagrees.
