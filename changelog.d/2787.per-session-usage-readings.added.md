- `GET /api/usage/sessions` and `GET /api/usage/sessions/:sessionId`: a live, per-session
  usage-and-context reading for every running session — context-remaining percentage parsed
  from the session's own status line, weekly/5-hour quota from operator calibration, and a
  `lowUsageHandOffRecommended` flag (default threshold 12% remaining) for a mechanical
  low-usage hand-off, in place of an operator eyeballing each pane's own warning by hand (#2787).
