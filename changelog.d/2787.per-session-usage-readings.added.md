- `GET /api/usage/sessions` and `GET /api/usage/sessions/:sessionId`: a live, per-session
  usage-and-context reading for every running session — context-remaining percentage parsed
  from the session's own status line, a Codex session's weekly quota parsed live from that
  same status line when present, and a `lowUsageHandOffRecommended` flag (default threshold 12%
  remaining) for a mechanical low-usage hand-off, in place of an operator eyeballing each pane's
  own warning by hand (#2787). Operator calibration remains the source for 5-hour quota (both
  engines) and for weekly quota when no live reading is present.
