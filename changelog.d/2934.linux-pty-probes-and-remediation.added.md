- Added Linux PTY exhaustion probing to the ttyd health detector
  (`lib/system-health.js#detectTtydLeak`): on `platform === 'linux'`, where
  there is no separate ttyd launchd job to measure the way macOS does, it
  now reads `/proc/sys/kernel/pty/nr` against `/proc/sys/kernel/pty/max`
  directly and fires at the same 85% threshold `ttyd-watcher.js` uses on
  macOS. Remediation strings in `lib/system-health.js` and `lib/master.js`
  are now platform-aware (`systemctl --user restart/status
  tangleclaw.service` on Linux, `launchctl` on macOS) instead of always
  naming the macOS command (#2934).
