- `lib/checkout-ownership.js` claims exclusive ownership of a worktree per live session (`claimWorktreeOwnership`/`readWorktreeOwnership`/`releaseWorktreeOwnership`, an atomic marker inside the worktree's own gitdir) and detects a foreign write landing underneath the owning session — `captureBaselineTreeState`/`verifyTreeUnchangedSinceBaseline` digest both the HEAD commit and every tracked/staged/untracked file's actual content, so a second edit to an already-modified file is caught even though its `git status` code doesn't change. `evaluateWorktreeWriteAdmission` composes both into one fail-closed admission check (#1332).
