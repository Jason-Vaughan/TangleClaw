- An attached image can now be previewed in the chat (#3083). A new `GET /api/sessions/<project>/secure-clipboard/<file>` route serves one pending image to the operator, and only an image: PNG, JPEG, WebP or GIF, checked by both its name and its leading bytes. Any other file in the project's secrets folder is refused with `415`, so a key or a text secret is never sent back. The file is read without following symlinks, and the response tells the browser not to guess its type, allows nothing but the image itself, and is never cached. A request carrying a project session's launch headers is refused, even alongside the operator's own. The operator can also force-send a message with `priority: true` on the session command route: it skips the waits ordinary work queues behind (an unfinished launch, an unconfirmed model) but never a hold, an engine startup dialog or a running wrap, and anyone but a proven operator asking for it is refused. A session that holds delegated lifecycle authority over another lane can now switch that lane's model at a safe boundary. Usage windows now report Antigravity alongside Claude and Codex (#3085), split a time-limited transcript scan fairly between the three so one large history cannot crowd the others out, and read a Codex session's live "5h NN% left" reading when its status line shows one.
