- Added an automatic startup announcement on the Medusa switchboard: once a
  session's launch sequence attests READY and its Medusa listener is
  active, it sends one `[Startup] <name> (<role>) online — session #<id>,
  workspace <workspaceId>, ready for switchboard work.` message to every
  other live session on the same project, so a coordinator can pick up a
  freshly-launched session without polling. Idempotent per launch
  sequence, and off via the project's own `startupAnnounceDisabled` config
  flag or the `TANGLECLAW_STARTUP_ANNOUNCE_DISABLED` env var (#1732).
