- `lib/bridge-notify.js` and `lib/workload-nudge.js` now auto-detect a live Fleet PM / Project Group coordinator (an active `project-manager` `coordinator_roles` row on a live-session group member) when a project names no explicit `workloadNudge.coordinatorProject` at all, routing its blocked/operator-needed Medusa delays to that coordinator instead of paging the operator directly -- a sub-lane freshly added to a Fleet PM's group is protected from the moment it joins, with no per-project setting to remember (#2853). An explicit `coordinatorProject` that fails never falls back to this auto-detect. `lib/bridge-notify.js` also adds a closed-loop `operator-resolved` all-clear follow-up, mirroring `_workUnblocked`'s own shape: once a delivered `operator-needed` alert's exchange resolves (read/acknowledged/replied/closed), one idempotent follow-up notice tells the operator the earlier alert can be disregarded.
