- The v6 chat makes links clickable and keeps the chat focused (#3082). Web links and Markdown links in messages open in a new tab (only `http:` and `https:`, never `javascript:` or `data:`). A link to an image on another site shows as a link card and is never loaded in the chat, so a message cannot make the browser fetch it. An image attached to a message shows as a thumbnail that opens in a new tab; it is fetched once with the operator's proof and kept while the chat is open. Under the Hood gains checkboxes for which switchboard-triggered replies show in the chat: Blockers and Milestones on, Fleet chatter off by default. The rest are listed there with a count, and direct chat and questions always show. A ⚡ Force button (or Ctrl/Cmd+Shift+Enter) sends a message at once, even while another send or a reply is in flight; the server still refuses at an engine startup dialog, a running wrap or a hold, and the chat shows why and puts the text back. In the v6 shell the chat's header now sits in the dashboard's top bar, so there is one bar instead of two, and the CPU, memory, disk and uptime readings move to the footer.
