- `lib/branch-ownership.js` binds a branch to one active owner generation (`bindBranchOwnership`), requires proving the prior owner has nothing unpublished before a `handoffBranchOwnership` transfer, binds review evidence to the exact head it was recorded against and drops it on any rewrite (`recordReviewEvidence`/`invalidateReviewEvidenceOnRewrite`), and fails closed on a cross-owner mutation of someone else's branch — `evaluateBranchMutationGuard` returns `CROSS_OWNER_FORCE_PUSH_FORBIDDEN` specifically for a force-push, `CROSS_OWNER_BRANCH_MUTATION_FORBIDDEN` otherwise, with no staleness escape (#1977).
