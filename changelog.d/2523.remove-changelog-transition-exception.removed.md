- Removed the pre-boundary changelog transition exception: a direct edit to `CHANGELOG.md`'s `[Unreleased]` section no longer satisfies the `changelog-update` wrap step under any circumstance. `lib/wrap-default-pipeline.js`'s `changelog-update` step no longer declares `CHANGELOG.md` in `verifyChanged` at all — leaving it declared let the gate's mutation check (`lib/wrap-steps/ai-content.js`) pass a bare direct edit unconditionally, with no fragment required, since that check is satisfied the instant any ONE of a step's declared paths changes. Only `changelog.d/` is declared now, so a direct edit falls through to `lib/wrap-steps/changelog-coverage.js`'s predicate, which recognizes a correctly named fragment (or a project's declared `coveragePaths`) and nothing else. A caller declaring only `CHANGELOG.md` (no fragments) is unaffected. `lib/wrap-default-pipeline.js`'s `changelog-update` prompt, `docs/changelog-fragments.md`, and `CONTRIBUTING.md` no longer describe the now-closed pre-boundary exception (#2523).
