- Files can now be attached to a v6 chat message by dropping them on the composer, pasting them (screenshots included) into the message, or the 📎 Attach button (#3053). Each file is uploaded into the project's secrets store through the existing secure-clipboard route, shown as a removable chip, and referenced in the sent message by the path the agent can open; a file over 5 MB, or one the server refuses, says why on its chip, and a message waits while a file is still uploading. An offline chat now offers ▶ Start (and a link to the Classic launcher for a start that needs its dialogs), a project or fleet with offline members offers to start them all after a second click, and an offline chat turns Active by itself once its session starts. Clicking any sidebar link, including the one already open, refreshes session state. A lane reached by clicking it directly is shown as the Designated Project Delegate when it is one, and the chat no longer repeats the Classic View link or shows the template and attestation pills.
