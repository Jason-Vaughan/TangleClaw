- The Operator's own edit of an active, non-master project rule now takes effect in one step: `PUT /api/session-rules/:id` applies it immediately as an already-approved replacement rather than filing a replacement proposal the Operator would then have to approve themselves. A session acting on a rule's behalf, a pending replacement from someone else, and a version rollback are unaffected and still go through approval. The Project Rules modal gained an Edit control on live rules, with a plain notice that saving takes effect immediately and running sessions pick it up at their next rules read (#2325).
