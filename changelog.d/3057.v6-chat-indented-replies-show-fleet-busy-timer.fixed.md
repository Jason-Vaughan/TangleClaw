- The v6 Project Delegate Chat no longer drops an agent's reply that follows a tool line (#3057). Antigravity indents its reply prose by two spaces, and the chat read every indented line after `● Explored …` or `● Ran …` as that tool's output, so the reply never appeared as a bubble; now, under a tool line, only its `⎿`/`└` output or a line indented four or more spaces is treated as output, in every engine, so a reply indented by two spaces is kept, even after a blank line. With the Fleet sidebar hidden, the chat's own action bar offers `» Show Fleet`, and the page header holding the other `» Show Fleet` stays in view while the page scrolls. The busy line shows animated dots and how long the agent has been working (`0s`, `1m 12s`), starting as soon as a message is sent and stopping when the agent is done. The chat header shows the target project's own version (or latest tag) and git branch, starred when it has uncommitted changes.
