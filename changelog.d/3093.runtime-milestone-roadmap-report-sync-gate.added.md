- Sprint setup can now be checked at runtime before Gate 0 and Sprint Exit are certified (#3093). `verifySprintSetupAndRoadmapSync` in `lib/native-sprint-tracker.js` holds certification when an open `vX.Y.Z` milestone has no release in the roadmap, an issue is placed more than once across the roadmap's releases, unversioned trains and backlog, the roadmap sync status is missing or not `ok`, or a sprint report directory is not linked from the Sprint Reports Hub. It reports as its own runtime guardrail (`setup_and_roadmap_sync`), so the post-mortem ledger's P0–P11 rows are unchanged. The report validator gains `validateHubReportLinks` and `ensureHubReportLinks`: when the hub's live sprint card moves on to the next version, the version it used to link gets a card of its own instead of being left unlinked, and running it again changes nothing.
