- The Tests workflow's job limit is raised from 20 to 35 minutes (#3075). The suite, now about 30,900 tests, runs 16 to 20 minutes, so the 20-minute cap was cancelling healthy runs partway through, both on pull requests and inside the release workflow, which runs the same job before it tags a release. The job is still bounded, so a stalled run cannot hold a runner indefinitely.
