- The v6 chat is easier to scan and its header is slimmer (#3079). Each message is tinted in its own accent colour, blue for the operator and green for the agent, with a 1.5px dashed divider in that colour above its text; the tint is translucent in the dark and light themes. "Waiting on you" now lists every question in the agent's newest reply, not just the last line, numbered `(1)`, `(2)` when there are several. Each question has a ✕ to dismiss it, and the list clears when you reply. Active sessions, Health and Version moved from the header to the footer status bar. The member picker in the chat header is hidden, since the Fleet sidebar already switches members. While the Fleet Shell shows, Ports, Usage, Groups, OpenClaw, Audit, Recovery, Global Rules and Sign out sit in a "⋯ More" menu; Classic View, Master and Advisor stay in the bar, and Classic View puts every control back. A message longer than the 4,096 characters a session command takes no longer fails: the chat saves the whole message as a file in the project's secrets store (up to 5 MB, under a name no saved file already has, and only when that store can be checked), then sends the session as much of its start as fits, followed by the file's path. The conversation records the whole message when it fits the record's 8,000-byte limit; otherwise it records the start and the file's path. Pressing Enter now clears the message box at once and shows the message at the bottom of the chat while it is sent; if the send fails, the text comes back. Your messages and the agent's replies now show in the order they happened, each once, instead of all your messages gathering above the replies.
