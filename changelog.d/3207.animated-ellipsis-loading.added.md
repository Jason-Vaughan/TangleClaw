- Added a shared, subtle animated ellipsis loading indicator to
  `public/api-helper.js` (#3207): `tcV6AnimatedEllipsisMarkup(label)`
  renders a static `<span class="v6-loading-indicator">` for any
  context-specific label ("Loading chat...", "Connecting...", "Starting
  session...", "Retrieving history...", "Refreshing usage...", or a
  custom string), normalizing any trailing dots/ellipsis in the label so
  it is never doubled up with the animated ones.
  `tcV6CreateAnimatedEllipsisController(opts)` mounts a live version that
  cycles its ellipsis `.` → `..` → `...` → `.` on an interval, skips the
  animation entirely (a static `...`) under `prefers-reduced-motion:
  reduce`, and can update its own label, stop cleanly, or fail into an
  actionable error message with an optional Retry button — a single
  implementation for every page currently rolling its own wait state.
