- An async, bounded, non-blocking project-path I/O primitive layer (#1350): `lib/projects-async-io.js` provides `readProjectFileAsync`/`statProjectPathAsync`/`scanProjectMetadataAsync`, each an `fs.promises`-based reader with bounded concurrency, a caller-visible timeout (so a stalled or TCC-protected mount can no longer wedge the server for the life of the process), and a short-TTL cache that never caches a failure. This slice is the reusable primitive module only; replacing `lib/projects.js`'s 43 synchronous reads with these readers is tracked as a later slice.
