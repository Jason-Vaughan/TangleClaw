- `lib/untrusted-pr-review.js` sanitizes and non-executably fences untrusted external PR text (title, body, commit messages, review comments, diff hunks) before an agent reviews it, and checks a review session's declared capabilities (checkout mode, stripped secrets, allowed actions) against the read-only review contract ADR 0014 requires. It complements, and does not replace, the ADR 0014 rule 3 injection-hold operating rule (#1554).
