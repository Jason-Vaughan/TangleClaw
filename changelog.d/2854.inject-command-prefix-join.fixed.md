- `lib/sessions.js#injectCommand` now joins its server-added `serverPrefix` stamp (the verified-caller `[DIRECT INPUT ...]` line) to a single-line `command` with a single space instead of a newline, so a single-line peer `/command` injection no longer becomes a two-line bracketed paste that some engine TUIs (Codex included) submit on the first Enter while leaving the prefix's own line stranded, unsubmitted, in the composer (#2854). A `command` that is itself multi-line keeps the newline join, since the two are already visually distinct lines.
