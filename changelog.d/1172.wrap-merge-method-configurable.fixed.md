- The wrap pipeline's auto-merge now uses a configurable `gh pr merge` flag instead of a hard-coded `--squash`: both `lib/wrap-steps/pr-merge.js` (the session-scoped PR gate's auto-merge enqueue) and `lib/wrap-steps/commit.js` (the auto-branched commit's auto-PR close-loop) resolve the flag through the new `resolveWrapMergeMethod(projectPath, options)`, exported from `pr-merge.js` alongside `VALID_MERGE_METHODS` and `DEFAULT_MERGE_METHOD` (#1172). Precedence: an explicit caller option, then `wrapMergeMethod` in `.tangleclaw/project.json`, then a `PR merge strategy` row in `.prawduct/artifacts/project-preferences.md`, then `"squash"` — so every wrap that configured nothing keeps its prior `--squash` behavior unchanged. An unrecognized value at any source falls back to `"squash"` with a logged warning rather than failing the wrap.
