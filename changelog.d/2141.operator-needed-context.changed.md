- `operator-needed` Discord alerts now name the sender, priority, age and exchange id instead of a
  bare sentence naming only the recipient, and are suppressed for a recipient whose
  `coordinatorProject` has a live session — the same coordinator-first suppression `work-blocked`
  already had (#2620) — so a lane under a live coordinator is not paged to Discord twice. A new
  `work-unblocked` recovery notice is raised when an announced block clears, so the operator is
  told when a blocked lane is clear again, not just when it blocked (#2141).
