  • 3. Autonomous Observer Liveness Watchdog (Rule #283 cl. 1(c)) When TC-Lane-INT ended its turn waiting on post-merge main CI in Wave 3 (T01 and S06), TC-Lane-Obsr automatically nudged TC-Lane-INT after the 30m threshold, recovering dispatch in 37s and 45s with 0 Operator intervention. In Waves 4–5, TC-Lane-INT kept gh run watch active in-turn (0m stall).
  • 4. Exact JUnit Node Conservation (PR #2542) & Independent PR Reviewer W4-02 proved testcases (21,986) + testsuites (4,487) == runner tests + suites (26,473), and the pre-suite Independent PR Reviewer caught 4 dropped source-reader tests on W3-S03 before merge.
  • 5. Mid-Sprint Claude Opus 5.5 Cutover on TC-Lane-A Switching TC-Lane-A from Fable 5.1 to Claude Opus 5.5 after W4-04 produced 4 consecutive first-pass PRs (#2550–#2553) with 0 review rework rounds and 0 test retries.

⚠️ What Didn’t Work & Proven Fixes for v5.36.0

  • 1. ~9h 05m Local SUITE_SLOT Tax & Legacy prawduct-hook Truncation (F3, F5, #2371, #2521) Running 28 local full suites consumed ~9h 05m (including 40m on two pure-Markdown PRs #2517 and #2552), and legacy prawduct-hook omitted 41.9% of JUnit leaves on PR #2520. Fix: Activate #2371 (Stages 1–3 + test-touched.js locally in <30s + GitHub CI for full suite) and exempt check-pr-doc-only PRs from SUITE_SLOT.
  • 2. 4h 16m Unwoken Bridge Candidate Stall (F14, #2547) tc candidate submit and bridge-gateway.reconcile() did not wake Project Master on state = 'submitted' rows, leaving the Opus 5.5 cutover candidate unread for 4h 16m. Fix: Land #2547 in v5.36.0 Wave 1 (mitigated mid-sprint by pairing tc candidate submit with a direct Medusa wake).
  • 3. Terminal DA1 Escape Residue & Multi-Row Stranded Nudge Clearing (F4, A426 F16) Leaked DA1 response text (0;276;0c) blocked Codex wake delivery for 46m on PR #2518, and a 3-row wrapped nudge in Antigravity resisted single-line Ctrl-U clearing. Fix: Strip DA1/DA2 sequences and clear all wrapped rows in lib/tmux.js.
  • 4. tc finalize Refusal on send_unknown (hub_id: null) Exchanges (#2554) When a sender’s Hub POST times out locally, the orphaned send_unknown row has hub_id: null (un-ackable by recipient) yet blocked tc finalize in _obligations(). Fix: Filed #2554 to ignore hub_id: null rows in recipient obligations; completed fleet retirement cleanly via /wrap/complete.
  • 5. Detached Subshell macOS TCC Documents EPERM (F15) Detached subshells lost direct ~/Documents read access late in the sprint. Fix: Used /tmp/tc-cli/bin/tc + HTTP plan routes with 0 downtime, and documented granting tmux / agy Full Disk Access in HOST_MACHINE_OPTIMIZATION.md.
