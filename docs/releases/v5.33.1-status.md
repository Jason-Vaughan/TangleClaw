## Why 5.33.1

## What it contains

- **#2403, fixed by PR #2404** (merge `29e97d73`): a Master auto-started at boot could lose the bridge credential it was being handed, because the server reconciled the previous run's credentials after the launch. Boot now reconciles first, then starts the Master. Reviewed under the Architect's rulings A7, A8 and A10. The full local suite passed on its head `08832520`, as did CI.
- **Records PR #2405** (merge `4e8b1c41`): the changelog entry.

The hook itself was never run. The Architect reviewed the exact diff and passed its content (A13). The Operator accepted this disposition for #2405 only ("records accepted", typed in the Integrator's pane). The rule is unchanged.
- **#2390, #2391, #2392**: documentation of the v5.33.0 release status.
