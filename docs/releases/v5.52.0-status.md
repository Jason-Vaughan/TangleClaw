They were compiled into the dated `[5.52.0]` section and consumed. The two earlier Wave 1 fragments for #1380 and #1415 were editorially reconciled in the release notes to reflect the server wiring completed by Wave 2. `version.json` is this repository's version source; there is no `package.json` or `package-lock.json`. `scripts/release-prepare.js` refreshed README clone pins and extended the immutable released-section lock.

The #2771 warm cache does not remove the prior cold or expired sequential facts scan latency. A second install on the same machine remains unsupported (#1283). Caddyfile auto-fronting of PortHub leases was ruled out by source verification; an existing live-file check covers hand-added sites (#1340). Session-start and Medusa peer links remain loopback-only by design under Architect Ruling A490-W2A-R3.
