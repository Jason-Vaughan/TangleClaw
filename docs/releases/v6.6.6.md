# v6.6.6 — Fleet-isolated sprint data, provisioning hardening, and closed-loop Kaizen

TangleClaw v6.6.6 is the release-cut candidate for the completed v6.6.6 Wave 1. The release cut is dated 2026-11-27.

## Added

- **Closed-loop Observer Kaizen Gate 0/Gate 4** (#3324): ingests structured findings from settled sprint reports into the Kaizen ledger, exposes scoped `tc kaizen` commands for listing and disposition, records prior-sprint dispositions in the Functional Charter, and can refuse Sprint N+1 admission while prior findings or reports remain unsettled.

## Fixed

- **Fleet provisioning and project settings** (#3322, #3329, #3331): preserves each member's requested engine through attachment, avoids duplicate onboarding trust-rule proposals, resumes interrupted member provisioning safely, supports model/effort changes under bypass-permissions launch modes with confirmation, and keeps save errors next to the Save button.
- **Project/fleet sprint-data isolation** (#3325): scopes sprint-wave, sprint-report, and GitHub activity reads to the selected project's checkout and shared directory, and filters persisted wave runs by project/fleet.
- **V6 chat interaction reliability** (#3326, #3327, #3328, #3330): protects selections across background refreshes, fixes slow-scroll pinning and duplicate send bubbles, removes the closed Under the Hood drawer from layout, and labels prompts queued behind an active turn.
