# v6.2.10 — Clickable links, attachment previews, a verbosity filter, Force Send and a three-engine usage meter

TangleClaw v6.2.10 is a release on top of v6.2.9, from the operator's live walkthrough. The v6 chat makes links clickable, previews attached images, lets you choose which switchboard-triggered replies show, and can force-send a message while a reply is in flight. The shell gains a usage meter for Claude, Codex and Antigravity, and one top bar instead of two.

## Upgrade note

- **Database schema v84** (Ruling A758): on first start, the `usage_calibration` table is rebuilt so it can hold an Antigravity calibration. Every existing Claude and Codex calibration is copied across unchanged, and a database that is already at v84 is left alone.

## Added (filed as Fixed)

These are new features. To keep the v6.2.x patch train they are filed under Fixed, so this release is the patch 6.2.10 rather than 6.3.0.

- **Clickable links and attachment previews** (#3082, #3083; tests in `test/v6-b1-ui-shell.test.js`, `test/v6-browser-shell-and-conversation-e2e.test.js` and `test/secure-clipboard.test.js`): web and Markdown links in messages open in a new tab, `http:` and `https:` only. An image attached to a message shows as a thumbnail that opens in a new tab. It is fetched once, with the operator's proof, from a new operator-only route, `GET /api/sessions/<project>/secure-clipboard/<file>`, which serves only a PNG, JPEG, WebP or GIF, checked by both its name and its leading bytes. Any other file in the project's secrets folder is refused with `415`, symlinks are not followed, and the response is never cached. A link to an image on another site shows as a link card and is never loaded in the chat, so a message cannot make the browser fetch it.
- **Verbosity filter** (#3082): Under the Hood has checkboxes for which switchboard-triggered replies show in the chat. Blockers and Milestones are on and Fleet chatter is off by default. The rest are listed there with a count; direct chat and questions always show.
- **Force Send** (#3082, #3083; tests in `test/api-sessions.test.js`): a ⚡ Force button, or Ctrl/Cmd+Shift+Enter, sends a message at once, even while another send or a reply is in flight. It uses `priority: true` on the session command route, which only a proven operator may ask for. It skips the waits ordinary work queues behind (an unfinished launch, an unconfirmed model) but never a hold, an engine startup dialog or a running wrap; the chat then shows why and puts the text back.
- **Three-engine usage meter** (#3085; tests in `test/usage-windows.test.js` and the shell tests): the v6 footer shows a bar each for Claude, Codex and Antigravity, green, then amber at 25% left or less, and red and pulsing at 5% or less. It uses the lowest "% left" a live session reports and otherwise the operator's calibration. Clicking it opens each engine's 5-hour, weekly and sprint token totals, its live sessions, the time to the weekly reset, and a one-click "% left" calibration. Usage windows now report all three engines, split a time-limited transcript scan fairly between them, and read a Codex session's live "5h NN% left" reading when its status line shows one.

## Fixed

- **Delegated model switch** (#3083): a session that holds delegated lifecycle authority over another lane can now switch that lane's model at a safe boundary.
- **One top bar** (#3082): in the v6 shell the chat's header sits in the dashboard's top bar, and the CPU, memory, disk and uptime readings move to the footer.
