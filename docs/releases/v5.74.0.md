# v5.74.0 — Model + effort picker, boundary model-switch admission, and Aider fleet qualification

Milestone #62 had 2 open and 4 closed issues when this release candidate was cut — the two open issues (#1564, a real-host Linux systemd VRF; #2258, the actual Vercel/GitHub Pages cutover) need Operator-performed, physical-host or dashboard action beyond this code release and are tracked separately. The dated [5.74.0] section of `CHANGELOG.md` compiles and consumes 4 accepted fragments.

- Added a model + effort picker to Project Settings and the Launch Modal for Claude and Codex, applied at the next launch and shown next to the engine's own health status on the Session Banner when it differs from what the running session actually launched with (#2188, PR #2974).
- Fixed `tc model switch`/`POST /api/sessions/:project/switch-model` refusing a session's own self-service boundary switch while its CLI turn was still in flight, and refusing a verified Fleet Coordinator switching a sibling lane in its own namespace (#2598, PR #2973).
- Qualified Aider fleet sessions without startup URL scraping or false shell-readiness claims, added measured Medusa wake detection for Aider's own composer prompt, and bounded one-shot tasks to their explicit file envelopes, including rejecting control-character rule injection in task-scoped `.aiderignore` paths (#2961, PR #2972).
- Made Vercel configuration explicitly skip `gh-pages` builds and prepared tested `/roadmap/` and `/reports/` static export targets ahead of the public-site cutover; the cutover itself is Operator-performed and tracked separately under #2258 (#2258, PR #2971).
- Generalized the Shared roadmap/sprint-report sync scripts to resolve the active or newly-graduated milestone dynamically instead of a hardcoded version, and to never overwrite a finalized Gate 4 report (#2970 — `TangleClaw-Shared`, a separate, remote-less local repo; no PR in this repository).
