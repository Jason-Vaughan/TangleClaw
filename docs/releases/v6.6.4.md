# v6.6.4 — Engine failover, delegate succession, lifecycle progress, and settings parity

TangleClaw v6.6.4 is the release-cut candidate for the completed four-car Wave 1. It includes the four authorized v6.6.4 fragments. The release cut is dated 2026-11-27.

## Added

- **Configurable engine fallback chains** (#3271): per-member primary, secondary, and tertiary engine/model/effort profiles, deterministic failover triggers, bounded retries, and return-to-primary behavior when the primary recovers. Fleet settings UI and a live health-check loop remain follow-up work.
- **Delegate role succession** (#3272): configurable primary-to-surrogate delegate failover and recovery, with a split-brain guard that requires the store to confirm the genuinely live active coordinator.
- **Lifecycle stage progress** (#3277): startup and wrap progress indicators and human-readable stage labels driven by runtime telemetry. V6 shell mounting remains follow-up work.
- **Project settings parity endpoint** (#3278): `GET /api/projects/:name/settings-parity` returns resolved project configuration with a schema-drift audit for authorized callers.
