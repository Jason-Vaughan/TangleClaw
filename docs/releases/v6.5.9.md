# v6.5.9 — Session launch preflight, offline session hero, sidebar actions & Start Fleet, full-page Settings model picker, and Admin Fleet V6 Chat & uploads

TangleClaw v6.5.9 is a minor release on top of v6.5.8. A new session launch preflight check (`GET /api/sessions/:project/preflight`) classifies a launch problem into 5 structured categories before the operator ever clicks Launch, and a failed launch itself now returns the same structured diagnostic. V6 Chat's offline sessions get a focused startup hero with Start/View Previous Conversation/Edit Session Properties actions instead of a dead stream, and the Fleet Sidebar gained consistent per-row Rename/Edit/Start actions, a lifecycle status pill, and a consolidated ~12-second status poll that no longer goes stale for sessions other than the one currently open. The Fleet & Workspace Overview now defaults to "All Fleets" per browser tab instead of inheriting a previous fleet filter, and a one-click "▶ Start Fleet" button launches every offline member of a fleet at once. Project Settings is now a true full-page view with a real 3-phase AI model picker (Engine → Model → Effort) for Claude Code and Codex. Renaming a project now automatically migrates Claude Code's own encoded session-state directory instead of refusing the rename. Admin Fleet (`Admin-PM`) file uploads are no longer restricted to images, filenames with spaces or special characters are sanitized automatically, and the Master panel gained a drag/paste file dropzone and an integrated V6 Chat surface. Milestone [#103](https://github.com/Jason-Vaughan/TangleClaw/milestone/103): 9 of 9 issues closed.

## Added

- **Session launch preflight & structured launch diagnostics** (#3202): `GET /api/sessions/:project/preflight` runs fast, non-mutating readiness checks that classify a launch problem into 5 structured categories — `workspace_missing`/`filesystem_permission_denied` (macOS Full Disk Access), `engine_binary_missing`, `engine_auth_or_config_invalid`, and `launch_blocked_or_timeout` — each with a `title`, `message`, `remediation`, `retryable`, and `canEditProperties: true`. A failed `POST /api/sessions/:project` launch now surfaces the same structured `diagnostic` for a missing/unreadable workspace path, an unreachable tmux server under a TCC-protected folder, a malformed `.tangleclaw/project.json`, or explicit Codex auth failure, without preempting any condition `launchSession` already classified with its own specific status.
- **Offline session hero in V6 Chat** (#3203): an offline session shows a focused card with Start Session, View Previous Conversation, and Edit Session Properties, instead of a dead stream and a disabled composer. Starting shows an animated "Starting…" state; a refused launch shows the server's reason and, once available, the structured diagnostic's title/message/remediation. "View Previous Conversation" loads the project's persisted B2 conversation events, falling back to the continuity wrap-summary sections the sidebar's history panel already reads.
- **Fleet Sidebar per-row actions & lifecycle recovery** (#3205): Rename, Edit Session Properties and Start now sit together in every member's `.v6-tree-member-actions`, reachable regardless of whether the session is running, starting, offline or stopped — no chat needs to be open first (Start is left off a running member's row). A new lifecycle status pill (starting/failed/offline) surfaces a launch this UI just attempted, including one started from the sidebar itself, ahead of the next status poll, with a failed launch's own server message on the pill and Start still available to retry it.
- **Full-page Project Settings & 3-phase AI model picker** (#3214): the Settings modal is now a true full-viewport page — a sticky header, a scrollable body grouped into Identity & Workspace Paths / AI Engine, Model & Effort / Switchboard, Wake & Governance cards (the Identity card also surfaces workspace path existence/readability and git-repository status, plus the Fleet Coordinator role), and a persistent Cancel · Save Properties · Save & Launch / Restart Session action bar. Claude Code gets a real model selector (Sonnet, Opus, Fable) alongside its reasoning-effort levels, joining Codex's Phase-2 model axis; Antigravity and Aider show the same 3-phase card shape with a disabled "Engine default" placeholder until each has a post-launch model-verification path. A project stored under a custom Claude Code profile variant normalizes to plain Claude with a sensible model/effort default instead of showing as a separate, unpickable engine row.
- **One-click Start Fleet** (#3215): a "▶ Start Fleet (N)" / "▶ Start Offline (N)" button on each fleet group, in both the Fleet Sidebar and the Fleet & Workspace Overview's card headers, shown whenever a fleet has one or more offline members. Launches only the offline members, sequentially, continuing past an individual refusal rather than aborting the batch, and never restarts an already-live member; the button disappears once every member is running.
- **Automatic engine-state migration on project rename** (#3196): renaming a project now automatically migrates Claude Code's own encoded session-state directory (`~/.claude/projects/<encoded-old-path>` → `<encoded-new-path>`) instead of refusing the rename or demanding manual confirmation. A target collision, a filesystem error, or Codex's content-keyed rollout state (which can't be relocated by moving a file) still surface a clear warning with a manual `mv` fallback.

## Fixed

- **Fleet Sidebar stale lifecycle indicators** (#3201): `GET /api/projects` and `GET /api/models/status` previously refreshed only on initial route entry, so the sidebar could show stale status for sessions other than the one currently open. A consolidated refresh now also runs roughly every 12 seconds — piggybacked on every 3rd tick of an open chat's existing 4-second poll, or a standalone timer on routes with no chat poll of their own — and immediately after any Start/Start Fleet action, without resetting the chat composer draft, focus, or scroll position.
- **Fleet & Workspace Overview fleet filter isolation** (#3204): navigating to Overview now defaults the fleet filter to "All Fleets" instead of staying locked to whatever fleet a previous conversation or project route last narrowed it to. The filter itself moved from shared `localStorage` to tab-scoped `sessionStorage`, so two browser tabs on different fleets no longer read back each other's selection.
- **Admin Fleet file uploads & dropzone** (#3218): the Master control bar's file picker no longer carries `accept="image/*"`, so standard documents (MD, TXT, JSON, PDF, logs) can be attached the same way V6 Chat and Classic project upload already allow. A chosen, dropped, or pasted file's name is normalized to a `SAFE_FILENAME_RE`-compliant form automatically (a macOS screenshot name, or any name with spaces or parentheses, would otherwise be rejected outright), with repeated names in one batch deduping as `-2`/`-3`/… Added a shared `tcBindMasterDropzone` iframe-safe drag-over dropzone overlay and clipboard-paste file intake for the Master panel, and an integrated Admin Fleet V6 Chat surface (`#masterChatStream`, a collapsible Under the Hood terminal toggle, and a composer with attach/staged chips and one-click Send into `Admin-PM`) alongside the existing Admin Fleet governance bar.
