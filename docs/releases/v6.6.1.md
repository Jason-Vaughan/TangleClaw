# v6.6.1 — TCC-bootstrapped Codex startup, offline conversation history, and V6 layout fixes

TangleClaw v6.6.1 is a patch release that fixes Stage 2 test isolation, native startup and model verification for TCC-bootstrapped Codex sessions, offline conversation-history controls, and two V6 chat layout issues.

## Fixed

- **Stage 2 test isolation** (#3254): the touched-test gate no longer blocks changes to `lib/tmux.js` on three confirmed, unrelated pre-existing failures. The TCC and session-name tests remain in the gate.
- **TCC-bootstrapped Codex startup and model verification** (#3257, #3273): session creation captures the real pane and server from the TCC-authorized tmux server; pane reads route through that server; and a Codex launch that remains unobserved through launch-time retries is rechecked against the engine rollout file.
- **Offline conversation-history controls** (#3258): the V6 shell wires the previous-conversation and return-to-start-card actions, letting an offline session load its latest persisted conversation without starting the engine.
- **Usage popover viewport clamp** (#3270): the engine usage/status popover anchors from the right so it remains inside the viewport.
- **Composer layout** (#3276): the stream, Under the Hood and composer now use the chat column's available height down to the footer.
