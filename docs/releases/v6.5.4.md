# v6.5.4 — V6 scroll & chat reachability restoration, per-engine next-reset countdown, and Gate 4 post-sprint report enforcement

TangleClaw v6.5.4 is a minor release on top of v6.5.3. The V6 shell's chat stream, Under the Hood pane, and composer scroll internally again instead of overflowing the viewport, and a dragged or saved composer/Under the Hood height can no longer push the chat input off-screen. The per-engine usage indicator — both the automated CLI probe backend and the bottom frontier engine usage popover/meter — now shows each engine's next 5-hour and weekly reset countdown and timestamp, not just the bare percentage. And `roadmapSyncStatus` now fails closed on a shipped version whose Gate 4 post-sprint report is still a live-tracking placeholder rather than settled content, with `GET /api/sprint-reports/:version` surfacing the parsed post-mortem for the Kaizen & Reports workspace tab. Milestone [#90](https://github.com/Jason-Vaughan/TangleClaw/milestone/90): 3 of 3 issues closed.

## Added

- **Per-engine next-reset countdown in the usage indicator** (#3174): `_parseClaudeUsageCli` now also parses the 5-hour session window's own reset line from `claude -p "/usage"`, and `renderUsageProbe` shows each window's reset timestamp alongside its percentage when the CLI reported one. The engine usage popover (`#v6EngineUsagePopover`) and usage meter (`#v6EngineUsageMeter`) render each engine's next-reset countdown and timestamp wherever the probe reports a `weeklyResetAt`/`fiveHourResetAt` — on each probe bar, including Fable/Antigravity sub-tiers, and in the manual-calibration table row and pill tooltip.

## Fixed

- **V6 shell internal scroll and chat reachability** (#3173): `.v6-shell-root`'s `align-items: start` let `.v6-shell-view` grow to its content height instead of stretching to its grid track, clipping the chat stream, Under the Hood, and composer, and sometimes pushing the composer off-screen. `wireComposerResize()` now also clamps a saved or drag-resized `tc_v6_chat_input_height` and `tc_v6_chat_uth_height` to viewport-relative bounds through a pure `clampChatPaneHeights` helper, applied on both restore and every drag-resize measurement, so an oversized persisted height can no longer push the chat stream or composer off-screen and lock scrolling.
- **Gate 4 post-sprint report enforcement** (#3175): `roadmapSyncStatus` now fails closed when the currently shipped version's `sprint-reports/vX.Y.Z/index.html` is missing from disk, or still carries the auto-generated live-tracker placeholder instead of a settled Gate 4 post-sprint report, alongside the existing missing-sync-status and unlinked-hub checks. `GET /api/sprint-reports/:version` also now surfaces `settled` and a parsed `postMortem` (`whatWorked`, `whatDidnt`, `rule283PassCount`) when the version's report has settled, so the V6 Kaizen & Reports workspace tab can show the post-mortem in-app.
