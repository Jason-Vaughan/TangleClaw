# v5.65.0 — Linux hosts and operator wiring

Milestone #50 had zero open issues when this release candidate was cut. The dated [5.65.0] section of `CHANGELOG.md` compiles and consumes 13 accepted fragments.

- Linux hosts gain a `systemd` user-service generator and install, uninstall, and status commands. The unit runs `node server.js` directly and keeps its `tmux` server alive across restarts (#1424). Physical Linux hardware verification remains tracked in #1564.
- A read-only cross-project version dependency registry identifies satisfied, outdated, and breaking edges without sending notifications or changing dependent checkouts (#777).
- `tc docs` now lists and shows product-manual sections and resolves AI documentation by topic, role, or command from local manifests (#2887).
- The generic control hold route no longer accepts a peer-pause reason that bypasses the dedicated pause path; coordinator-role retention preserves insertion order when timestamps tie; scratch installs seed a scratch-aware projects directory on first boot (#2832, #2834, #2871).
- Project and fleet helpers add bounded async companions, workspace-rename checks, and a resolvable shared-document link after provisioning (#2864, #2870). Roadmap, merge-gate, and scorecard adapters land as library surfaces; their deferred live entrypoints remain tracked in #2877, #2878, and #2883.
- The workload nudge monitor distinguishes a mid-session `AskUserQuestion` menu from a startup dialog. Merge guard and answer-delivery work remains open under #2866.
