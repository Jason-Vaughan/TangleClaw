# v6.2.8 — Chat history search and Recents, renaming a member from the chat, and the Open Hood link fix

TangleClaw v6.2.8 is a release on top of v6.2.7, from the operator's live walkthrough. The v6 chat gains a history and Recents panel with search across a member or a whole fleet, a member can be renamed from the chat, and the chat's Open Hood link works again. It adds no new routes or settings; it uses the existing session-history search and project rename routes.

## Added (filed as Fixed)

These two are new features. To keep the v6.2.x patch train, they are filed under Fixed (ruling A731), so this release is the patch 6.2.8 rather than 6.3.0.

- **Chat history and Recents** (#3066, tests in `test/v6-b1-ui-shell.test.js` and `test/v6-browser-shell-and-conversation-e2e.test.js`): the sidebar's `🕓` button (the slot v6.2.7 reserved) and a `🕓` among the chat's own buttons open a history panel. With no search it lists the member's recent saved sessions, newest first. A search looks through wrap summaries or full transcripts, for that member or for every member of its fleet at once, and shows which member and session matched. Any match opens a read-only snapshot with a "Reference in chat" button that adds it to the message box. Transcripts flagged as holding secrets are marked and never quoted.
- **Rename a member from the chat** (#3071): a `✎` button in the chat header opens an inline rename form (Save, Cancel or Escape). It uses the same project rename as the Classic settings and is disabled while that member's session is live. The header, the sidebar tree and the delegate picker show the new name at once. If the server warns about the rename, the warning is shown with a "Rename anyway" option, and the form keeps the typed name on any refusal.

## Fixed

- **Open Hood (Live Terminal) link** (#3073, tests in `test/v6-b1-ui-shell.test.js` and `test/session-banner-phone-actions.test.js`): the chat's `>_` link pointed at `/session.html?project=<name>`, which the session page read as a project called "session.html", so it never loaded. It now opens `/session/<name>`, the path the server serves, and the session page also accepts the older `/session.html?project=<name>` form. The Classic session page's "Fleet Shell (v6)" link from v6.2.7 is unchanged.
