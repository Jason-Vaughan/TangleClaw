# v6.2.0 — Multi-train simulator, external providers, Advisor, Medusa v2 compact wire and OS sandboxing

TangleClaw v6.2.0 completes the v6 roadmap's in-repo software (V6-31..V6-35; V6-01..V6-35 across v6.0.0, v6.1.0 and v6.2.0). It adds a multi-train what-if simulator, non-GitHub provider adapters, a hardened external project advisor, Medusa v2's compact wire core, and isolated-mode host sandboxing. All five are reachable through 10 operator-only `/api/v6/*` routes and two new Fleet Shell views. The server owns every security-bearing input. Each item below says what is reachable over HTTP; anything else is library-only in this release.

## Included

- **Multi-train what-if simulator** (#3001, E3b): deterministic scheduling across trains with cross-train dependencies, file locks, lane pools and quota budgets, reporting the critical path, bottlenecks, utilization and every unschedulable car with a reason. Over HTTP: `POST /api/v6/whatif/simulate` and `POST /api/v6/whatif/compare`, plus a sample simulation in the Fleet Shell (`#/settings/whatif`).
- **GitLab, Jira, Linear and Dolt provider adapters** (#3002, G2b): the same six-method provider contract as GitHub, with each provider's own webhook verification; capabilities a provider lacks are refused, never faked. Over HTTP: `GET /api/v6/providers/g2b` and `POST /api/v6/providers/g2b/normalize`, which exercise the adapters offline and make no network call.
- **Hardened external project advisor** (#3003, G4): read-only, symlink- and swap-safe file reads from a repository TangleClaw does not manage, scrubbed output, and per-tenant rate and spend caps. Over HTTP: `POST /api/v6/advisor/advise` (reads only under the operator-configured `TANGLECLAW_ADVISOR_REPOS_ROOT`, with server-set limits and protected roots, and checks the rate cap before reading) and `GET /api/v6/advisor/usage`. Per-tenant workspaces under `~/.tangleclaw/advisor/` are library-only.
- **Medusa v2 compact wire** (#3004, R-MED-1): an opt-in `m2` envelope with a lossless, tamper-checked human card; Merkle-rooted delta sync with full-frame recovery; a wake coalescer that never drops a completion or demotes an urgent one; and idempotent SQLite persistence. Over HTTP: `POST /api/v6/medusa-v2/compact` (renders and parses cards, computes Merkle roots and diffs, records nothing) and `GET /api/v6/medusa-v2/status`. Wake coalescing and message persistence are library-only.
- **Isolated-mode host sandboxing** (#3005, A1-Iso): plans a session as a locked-down container or a separate unprivileged uid, never downgrading a profile that requires isolation. Mount allowlists come only from host policy, and sensitive host paths are always refused. Over HTTP: `GET /api/v6/sandboxing/status` and `POST /api/v6/sandboxing/plan`, using server-derived host facts and granting no host mounts.
- **Platform view**: the Fleet Shell's `#/settings/platform` shows live provider, Medusa v2 and sandboxing status.
