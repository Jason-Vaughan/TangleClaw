# v6.0.0 — Unified v6 platform: project/fleet hierarchy, native conversation layer, closed-loop Kaizen, fleet-first UI shell, project charters, rich reports & search, and guided GitHub integration

Milestone #61 had 2 open and 19 closed issues when this release candidate was cut — the two open issues (#1564, a real-host Linux systemd VRF; #2258, the actual Vercel/GitHub Pages cutover) need Operator-performed, physical-host or dashboard action beyond this code release and are tracked separately, as in the prior release. The dated [6.0.0] section of `CHANGELOG.md` compiles and consumes 33 accepted fragments across all 15 PRs below (#3006–#3020), closing all 19 Core v6.0 issues (V6-01..V6-19) across three delivery Trains.

- Ratified ADR 0026 (Native Conversation Layer and Open Hood Contract), amending ADR 0008 Decision 6, with no runtime behavior change on its own (#2976, PR #3007).
- Added the server-pinned project authority registry — a default-deny `AuthorizationService` plus the trusted workspace/principal/membership/grant tables and the G1 lease/approval mint/revoke surface (#1149, PR #3008).
- Added the replay-safe runtime transition ledger and its read-only cross-plane reconciler across SQLite, tmux, Git, PortHub and Medusa (#2977, PR #3008).
- Added the unified runtime incident and recovery registry — a failure taxonomy with secret-redacted evidence capture and a bounded, circuit-broken recovery budget (#2978, PR #3008).
- Added the Unified Logical Project → Fleet → Resource Module / Checkout / Role Lease / Shared Asset hierarchy, with CAS-guarded lifecycle transitions and role-lease conflict guards (#2118, PR #3009).
- Added the Closed-Loop Kaizen Ledger — a 9-stage finding lifecycle, the 4-Class Evidence-Based Verification Matrix, and the non-binding Gate 0 planning feed (#2980, PR #3009).
- Wired the Stage 1 authority, transition-ledger and incident-registry modules, the C1 hierarchy, the Kaizen Ledger, and the Sprint Report Validator v3 into live `server.js` routes (BRIDGE-2, PR #3010).
- Added Sprint Report Contract v3.0.0: a ten-rule deterministic validator closing the v2.1.0-era intra-document/cross-source contradictions, with historical-errata remediation (#2979, PR #3006).
- Added the 4-Plane Documentation Model — a deterministic path classifier, a canonical write-boundary guard, a token-budgeted context-assembly compiler with a sha256 provenance manifest, and the Project SSOT Index generator/validator (#1151, PR #3011).
- Added the Starter Fleet Template Catalog — three versioned templates and a guided apply-wizard planner that starts only the PM seat on launch (#2984, PR #3012).
- Added the Global & Fleet/Project Telemetry Header's data model, with a visibility controller that structurally guarantees HIDE never means DISABLE (#2983, PR #3012).
- Added the Native Conversation Layer's ledger — append/replay/soft-delete for structured and pane-derived adapters, deduped across reconnects (#2982, PR #3014).
- Added durable cross-generation model/effort selection attestation, one record per session generation (#2985, PR #3014).
- Added the Three-Surface Split Branding & Attribution Policy, with two hard locks enforced at read time for `Client / External` repos (#2987, PR #3013).
- Added default-on Medusa communication and the mandatory Project/Fleet switchboard cross-project isolation check (#2986, PR #3013).
- Added the Fleet-First route-based application shell — client-side hash routing, a collapsible hierarchy sidebar, and render hooks for the telemetry header, fleet-template wizard, model-attestation indicator, and branding watermark, mounted additively alongside the existing dashboard (#2981, PR #3015).
- Wired the B1 UI shell, B2 conversation layer, B4 telemetry header, C2 fleet templates, D1 model attestation, E1 doc planes, G3 Medusa isolation, and H1 branding policy modules into live `server.js` routes (BRIDGE-2b, PR #3016).
- Added Native Configurable Project Charters — a draft/approve/activate/amend/supersede lifecycle with immutable version snapshots, role-scoped sign-off, and a declared-vs-actual resource drift check (#2126, PR #3017).
- Added Dual-Format Rich Report Presentation — 12 four-part explainable metric popovers, a 3-pillar progressive-disclosure switcher view-model, and a deterministic Print/PDF stylesheet (#2988, PR #3018).
- Added the report search indexer and "Ask This Report" citation drawer — deterministic lexical matching with exact, verbatim cited passages, no model call (#2989, PR #3018).
- Added guided 3-tier scoped GitHub integration — Tier 1 read/observe, Tier 2 role-lease branch/PR/issue write, Tier 3 distinct-operator-approved milestone/merge/release — with a durable idempotent outbox and the canonical provider adapter contract, schema v82 → v83 (#2990, PR #3019).
- Wired the project charter, rich report presentation, report search, and GitHub outbox/webhook modules into live `server.js` routes, including the external GitHub webhook ingress (BRIDGE-2c, PR #3020).
