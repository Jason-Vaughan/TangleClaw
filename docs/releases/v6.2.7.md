# v6.2.7 — A Fleet Shell link on every Classic page, a four-icon sidebar and a higher-contrast chat

TangleClaw v6.2.7 is a fix release on top of v6.2.6, from the operator's live walkthrough. Every Classic page now links into the v6 Fleet Shell, the Fleet sidebar's header is a compact row of four icons with a single fleet picker, and the chat window has stronger outlines and contrast. It adds no new routes or settings.

## Fixed

- **A Fleet Shell link on every Classic page** (#3065, tests in `test/session-banner-phone-actions.test.js`): the Classic session page and the OpenClaw view now have a "Fleet Shell (v6)" link in their banner; the dashboard already had one. On a session page, once the project has loaded, the link opens that session's own v6 conversation. It sits before Wrap and Kill, which stay last in the banner.
- **A four-icon sidebar header** (#3068, tests in `test/v6-b1-ui-shell.test.js` and `test/v6-browser-shell-and-conversation-e2e.test.js`): the Fleet sidebar's header is now a row of four symbol-only buttons with hover tips. `«` hides the sidebar, `❖` is the fleet view, `🔍` opens search and the engine filter, and `🕓` is reserved for recent chats (disabled for now). A single fleet picker (All Fleets, or one fleet) replaces the group pills. Closing search clears its text and engine filter, so a filter you can no longer see never hides projects.
- **Higher-contrast chat window** (#3068): the chat header, messages, Under the Hood drawer, message box and the sidebar's edge have thicker, higher-contrast outlines and a filled surface, with a lighter outline in the light theme. The agent's messages carry a green left accent and the operator's a blue one, and the message box has a 2px outline with a green focus ring.

## Removed

- **Multi-select fleet filter and Expand all / Collapse all** (#3068): as the operator asked, the sidebar's multi-row group pills, the Multi toggle (and Ctrl/Cmd/Shift-click to select several) and the Expand all / Collapse all buttons are gone. Each project and fleet keeps its own fold toggle. A selection of several fleets saved earlier still applies, and the picker shows it as "Several fleets".
