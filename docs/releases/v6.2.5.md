# v6.2.5 — The active lane marked in the Fleet sidebar and a one-row icon chat toolbar

TangleClaw v6.2.5 is a fix release on top of v6.2.4, from the operator's live testing of the v6 Project Delegate Chat. The Fleet sidebar now shows which lane a chat is talking to, and the chat's four-row header is now a single compact row of icon buttons with hover tips. It adds no new routes or settings.

## Fixed

- **The active lane in the sidebar** (#3059, tests in `test/v6-b1-ui-shell.test.js` and `test/v6-browser-shell-and-conversation-e2e.test.js`): the Fleet sidebar marks the lane a chat is talking to, even when the chat was opened from its project or fleet and resolved to the Designated Project Delegate. The active lane, project and fleet are bold, and the lane also gets an accent on its left edge.
- **A one-row chat header** (#3059): the chat's header is now one compact row. On the left are the lane's name, session, Delegate or Direct, status, and version and branch; the full description is a hover tip and is read to screen readers. On the right are icon buttons for Open Hood (`>_`), Refresh (`↻`) and Project Settings (`⚙`), each with a hover tip and an accessible label, plus the delegate picker or the switch-to-delegate chip. In a chat, the route and group headings are hidden from sight but kept for screen readers.
