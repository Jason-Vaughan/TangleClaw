# v6.5.2 — Full-viewport V6 layout, 3-pane resizers, generic overview, TCC bootstrap recovery, and targeted Medusa wakes

TangleClaw v6.5.2 is a minor release on top of v6.5.1. The V6 shell now fills 100% of any browser viewport with no outer wiggle and slim dark scrollbars everywhere; Chat Stream, Under the Hood, and the Chat Composer gained interactive 3-pane vertical resizers; every top-bar control stays directly visible inline with a direct engine switcher and session-edit control, replacing the old "⋯ More" menu; the Fleet view now opens on a generic, non-session Overview screen instead of auto-loading a project, with direct launch from every project card; a TCC tmux bootstrap duplicate-session failure now recovers automatically; the idle workload-nudge monitor no longer re-arms its own token-burn loop on a complete/safe-to-clear lane; and Medusa switchboard wakes are now targeted strictly at the session that owns the next action, suppressing startup-announce spam and FYI/receipt copies by default. Alongside these, a 2026-11-08 `Co-authored-by:` clean-room attribution amendment is reverted back to strict `Reported-by:` prose. Milestone [#87](https://github.com/Jason-Vaughan/TangleClaw/milestone/87): 8 of 8 issues closed (a 9th, follow-up issue landed in the same wave — see Verification).

## Added

- **Interactive 3-pane vertical resizers** (#3152): Chat Stream, Under the Hood (`#v6ChatPeek`), and the Chat Composer each gained a drag-resizable height, persisted across reloads, utilizing the full browser viewport height rather than a fixed proportion.

## Changed

- **Clean-room attribution reverted to strict `Reported-by:`** (#3150): the 2026-11-08 native GitHub `Co-authored-by:` amendment to ADR 0014 is reverted. Clean-room reconstructions once again use strict prose `Reported-by:` attribution only — no `Co-authored-by:` commit trailers, no `@username` PR mentions, and no `README.md` **Contributors** section — so an external reporter is never displayed as a repository commit co-author or contributor on GitHub.
- **Inline top-bar controls, no more "⋯ More" menu** (#3153): every top-bar dashboard control (Ports, Usage, Groups, OpenClaw, Audit, Recovery, Global Rules, Sign out) now stays directly visible inline. The chat control bar gains a direct, labeled "⚙ Edit Session" button and an inline engine picker, so switching a project's engine no longer needs the full Settings modal.
- **Targeted Medusa wake notifications** (#3155): routine session-startup announcements default to silent (opt in with a project's `startupAnnounceEnabled` or `TANGLECLAW_STARTUP_ANNOUNCE_ENABLED`), never wake the Architect by default, and `tc message send --no-wake` (`POST .../medusa/send` with `noWake: true`) delivers an informational/FYI/receipt copy to an inbox without typing an active pane wake for it. Documented single-action-owner targeting in the operating primer and CLI reference: message only the session that owns the next action.

## Fixed

- **TCC bootstrap recovery from a duplicate anchor** (#3148): `createSessionWithTccBootstrap` no longer leaks a Terminal.app window or fails with `duplicate session: tc-tcc-anchor` when the TCC-authorized tmux server can't read a protected `cwd` but the default tmux server already can — it now uses the default server directly in that case, evicts a stale TCC-authorized server holding only the anchor session before re-bootstrapping, and bootstraps with `new-session -A` so a pre-existing anchor is never a duplicate-session error.
- **Idle workload-nudge token-burn loop stopped** (#3149): a session whose newest workload receipt already reports `state: "complete"` or `clearance: "safe-to-clear"` is now never nudged or escalated, however long that receipt sits expired, instead of retyping the same report every 2 hours.
- **V6 full-viewport layout, no footer wiggle or light scrollbar** (#3151): `.main-scroll` and `.v6-shell-root` now fill exactly 100% of the space below the top bar (not an independent `100dvh`), and slim dark scrollbars apply globally. The chat view, detail pane, and composer wrapper are now full-height/resizable flex columns, closing most of the dead space below them.
- **Generic V6 overview and direct session launch** (#3154): entering the Fleet view now lands on a generic Fleet & Workspace Overview screen (or the sidebar's currently selected fleet) instead of always auto-loading the alphabetically-first project. The sidebar's fleet picker now navigates the main view when changed, and the Overview screen gets direct "▶ Start", an engine picker, "⚙ Edit Session" and "Open Chat" on every project card.

## Internal

- **Finished #3151's deferred criterion 3** (#3156): `.v6-chat-stream` no longer carries a `55vh`-relative `max-height` cap at all; it fills whatever `.v6-chat` has left via `flex: 1 1 0%` once Under the Hood and the composer have taken their own share, and the now-inert resize handle that cap's JS coupling used to drive has been removed along with it.
