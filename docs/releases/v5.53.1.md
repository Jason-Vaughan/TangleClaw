# v5.53.1 — Residual and spin-off closure

This patch release closes six residual and spin-off issues from v5.52.0 and v5.53.0. The [release status](v5.53.1-status.md) tracks code publication, the local server update, and live activation.

- `tc whoami` operator-host and setup cutover/restart redirects honor Tailscale advertisement mode. If its origin cannot be resolved, they report the failure instead of using the caller's Host header (#1380).
- A running Project Master now reports an estimated continuity reading from its live pane buffer when the caller supplies no reading. Empty or failed captures remain `unmeasured`; no automatic relaunch was added (#2120). The imported-project trust proposal from v5.53.0 remains in place (#2125).
- Caddy drift detects a proxy route reached before its required auth gate, including nested subroutes (#2774).
- Clipboard reads from tmux skip `tc-send-*` transport buffers and select an explicit named user buffer (#2773).
- The rule-receipt test reports a missing `curl` dependency clearly in the Testament pool (#2778).

The dated [5.53.1] section of `CHANGELOG.md` contains the five new release fragments. #2125 closes an already-shipped v5.53.0 behavior and has no new fragment.
