# v6.0.1 — Live Fleet Shell data, conversation detail, and Classic View switching

TangleClaw v6.0.1 wires the v6 Fleet Shell to live project, session, telemetry, template, conversation, and model-attestation data while preserving an immediate one-click return to Classic View.

## Included

- A top-bar **Fleet Shell (v6) / Classic View** switcher.
- Live Logical Project → Fleet → Member navigation synthesized from existing projects, including reliable logical-project and fleet landing routes.
- Conversation-event replay, model-attestation detail, and Open Hood terminal links.
- Live B4 telemetry with explicit observed, estimated, and unavailable confidence labels.
- C2 starter fleet-template loading and seat-plan previews.
