# v5.67.0 — Live fleet controls and release surfaces

Milestone #54 had zero open issues when this release candidate was cut. The dated [5.67.0] section of `CHANGELOG.md` compiles and consumes nine accepted fragments.

- Launches now place a role-aware `gh` wrapper on `PATH` to enforce Integrator merge authority. The durable merge-gate ledger is available through `tc` and live session routes (#2866, #2878).
- `tc roadmap admission|sync` and `scripts/roadmap-sync-check.js` expose roadmap checks for PM dispatch and the board generator (#2877).
- Continuity reads backfill native transcripts and badge their `native-log` or `live-capture` source in Session History. The project-scoped governed-wrap progress stream (`GET /api/sessions/:project/governed-wrap/:requestId/stream`) and loaded `public/governed-wrap-ui.js` helper are ready for UI call sites (#2881).
- Project-scoped `/api/sessions/:project/chunk-boundary*` routes and the loaded `public/chunk-boundary-ui.js` helper are ready for UI call sites; new launches and leases receive the operating primer (#2888).
- The local scorecard has an HTTP endpoint, optional scheduled refresh, and a guarded metrics publisher (#2883).
- Bridge step-up and Settings controls, lifecycle handoff progression, docs parity notices, and remote CA install plans are mounted in their live server or UI paths (#2884, #2885, #2886).
