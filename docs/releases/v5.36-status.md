## Why 5.36.0

The section holds `### Added`, `### Fixed` and `### Internal` entries and no `BREAKING` marker, which this repository's bump table reads as a minor release: 5.35.0 to 5.36.0.

## What it contains

`CHANGELOG.md`, section `[5.36.0]`, is the list: 9 top-level entries, 1 Added, 5 Fixed and 3 Internal. The release pull request compiled the 9 files under `changelog.d/` into `[Unreleased]` with `lib/changelog-fragments.js`, promoted that to `[5.36.0]` with `lib/wrap-steps/version-bump.js`'s own promote function, and deleted the fragments in the same commit, as a wrap's release cut does. It publishes 4,682 bytes of release notes against the release gate's ceiling of 120,000 (`node lib/changelog-notes.js 5.36.0`, measured by `node scripts/release-notes-gate.js`).

The milestone "v5.36.0: Startup dialogs, finished" holds 25 issues, all closed (`gh api repos/Jason-Vaughan/TangleClaw/milestones/21`: 0 open, 25 closed). #2544, whose first batch ships here, was moved to the v5.37.0 milestone and stays open (below).

The release ran as four waves on two Builder lanes, with an Integrator merging. In summary, by wave; the entries themselves are the authority:

- **Wave 1.** The `docs/releases/v5.35-status.md` post-release sync, Tests runnable by hand, and the doc-only fast path written down (#2559, for #2558). `scripts/record-test-run.js`, which records the suite so Prawduct cannot under-count node:test's report (#2560, for #2521).
- **Wave 2.** The same startup dialog recorded once, decided in the store (#2561, for #2195). A submitted candidate wakes the Master, and terminal residue no longer holds a wake (#2562, for #2547 and #2555).
- **Wave 3.** `tc finalize` retires a drained lane, its named coordinator may retire it, and the Master may close its own sends; `tc docs lock` and `tc docs unlock` (#2563, for #2554 and #2556). Tests pin that a slow project scan or OpenClaw version probe cannot delay the switchboard (#2564, for #2557).
- **Wave 4.** Two intermittent tests wait for the behaviour they assert instead of a fixed delay (#2567, for #2531 and #2546). The dead-export walker reads template and spread uses, and the 33 dead `lib/soak/` exports are retired (#2568, the first batch of #2544).

The store stays at schema 68. `CURRENT_SCHEMA_VERSION` is 68 at the `v5.35.0` tag and at `1a59ad68` (`lib/store/_schema.js`), and no migration was added. The store's code did change (`lib/store.js` and `lib/store/sessions.js`, from #2561), so the release head was rehearsed against a copy of the live store ("Upgrade rehearsal", below).
