# v5.56.0 — Switchboard delivery guarantees

This release candidate reconciles the closed issues in Milestone #41. The [release status](v5.56.0-status.md) tracks the code merge, tag, GitHub Release, local update, and live verification separately.

- Medusa delivery and operator visibility improve through a Bridge version tooltip, heartbeat timeout recovery, periodic delivery pruning, a bounded system-send timeout, and recipient-opening escalation actions (#1009, #1364, #2137, #2270, #2720).
- A stranded tmux wake nudge can be resubmitted by pressing Enter over the same text. This is tmux-layer recovery; it does not add an engine-native delivery receipt (#1621).
- A reply-required message cannot be acknowledged or marked complete while a reply is owed. Exchange queries can include the recipient's and sender's views (#1976, #2137).
- Senders can retract unread Medusa messages while retaining a durable tombstone (#1873). Shared-document notice coalescing now measures staleness against the newest pending notice (#2655).
- Callable CI state notification helpers send idempotent Medusa notices when invoked, but no HTTP GitHub webhook route invokes them yet (#1783). External escalation alerts require opt-in configuration and host integration; local dashboard alerts continue independently (#1876).
- Delivery documentation now reflects the verified launch-binding and sender-identity requirements (#2663).

The dated [5.56.0] section of `CHANGELOG.md` compiles and consumes the 12 accepted release fragments.
