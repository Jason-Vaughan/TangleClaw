# v6.5.1 — Waiting-On drill-downs, an automated CLI usage probe, the official brand palette, Under the Hood polish, and the Admin Fleet

TangleClaw v6.5.1 is a minor release on top of v6.5.0. The v6 chat's "Waiting on:" panel is now one unified, collapsible header with per-actor drill-downs; a backend CLI `/usage` probe reads real quota data with no model tokens spent; the v6 shell ships the official TangleClaw dark brand palette with a resizable, persisted sidebar and chat layout; Under the Hood gains deep scrollback, a Full-Screen view and an Interactive CLI mode; the sidebar gains inline rename; and the Project Master evolves into a governed **Admin Fleet**. Alongside these, the Sprint & Cars panel's display bugs are fixed and chat link-preview backend fixes close two root causes of the 90% "Preview Unavailable" rate. Milestone [#84](https://github.com/Jason-Vaughan/TangleClaw/milestone/84): 10 of 10 issues closed.

## Added

- **Unified Waiting-On panel** (#3131): the v6 chat's "Waiting on:" panel is now one outer header with collapsible, per-actor drill-downs — `YOU (x)` (CLI gates, multi-choice, direct questions and the operator's ToDo, combined), `AI (x)`, and a `<Fleet Member> (x)` section per outstanding outbound Medusa request, auto-clearing once a reply lands. Multi-item lists number as `1- `, `2- `. Live question detection no longer reads a superseded paragraph of the same reply, nor a line that merely echoes the operator's own words back.
- **Automated CLI usage probe** (#3132): `tc usage refresh`/`tc usage probe` (and `POST /api/usage/refresh`, `GET /api/usage/probe`) run `claude -p "/usage"` and `agy -p "/usage"` directly (no model tokens spent) and read a disposable Codex utility session's own status row, persisting weekly/5-hour/sub-tier remaining percentages and reset times across wraps. Configurable refresh cadence via `tc usage interval <15m|30m|1h|manual>`. Honest `configured`/`not-present`/`not-configured` status per provider.
- **Resizable, persisted layout** (#3133): the v6 Fleet sidebar gained a drag-resizable width, persisted in `localStorage` across reloads and clamped to 180–480px; the composer and chat stream's heights are now persisted the same way instead of resetting on reload. Stale composer drafts over 2KB are dropped automatically.
- **Sprint/roadmap and GitHub wiring** (#3134): `GET /api/sprint-waves` now reads a loaded roadmap (the real `roadmap2-data.json`, falling back to `docs/releases/*.md` and `LANE_QUEUE.md`), giving the Charter & Roadmap panel real release grouping and clickable PR links, a `🌐 Public SSOT Roadmap` link, and a new `GET /api/sprint-waves/github-activity` endpoint with a ready-to-mount GitHub panel renderer (live open PRs, issues, milestones, latest release).
- **Chat and Under the Hood polish** (#3135): the chat stream stays pinned to its newest line through a reload, a chat switch, and header docking, with a floating `↓ Newest` pill when the operator scrolls away. Under the Hood reads 2000 lines of scrollback (not 80), gains a `⤢ Full Screen` dark-overlay toggle, and a double-click (or `⌨ Interactive`) Interactive CLI Mode that types directly into the live pane.
- **Sidebar inline rename** (#3136): added inline `✎` rename (or double-click the label) directly in the v6 sidebar for Fleets, Fleet Members, and Solo Work projects, reusing the chat header's own rename route and orphan-risk confirmation; renaming a Fleet renames every current member with the same prefix, stopping on the first it cannot rename.
- **Admin Fleet** (#3137): evolved the Project Master into the **Admin Fleet**, led by **Admin-PM** (full backward compatibility with the existing `master`/`Orchestrator` API, Medusa routes and tmux session), with utility seats (`Admin-Claude`, `Admin-Codex`, `Admin-AGY`, `Admin-Advisor`) in the panel. Added a governed **Wrap & Relaunch** action (captures a continuity handoff capsule before restarting) with a low-context warning banner, and photo/screenshot attachments for Admin-PM.
- **Version-plan parallelism validator** (#3138): added `validateVersionPlanParallelism`, which refuses a version plan that dumps a parallelizable issue set into one un-parallelized train, or that lets two parallel trains in the same wave share a file; wired into `verifySprintSetupAndRoadmapSync` via its new optional `versionPlans` input.
- **Chat link-preview backend fixes** (#3139): a remote `.mp4`/`.webm`/`.mov` URL now classifies as a video-preview card instead of going to the HTML scraper; a page with no `og:*` tags now falls back to its `<title>`/`<meta name="description">`/`<h1>`/`<p>` text. Added `isAllowlistedUnfurlHost` for `*.ts.net`, `*.github.io`, and `tangleclaw.com` — not yet wired into the server's resolved-address SSRF recheck, so Tailscale links do not yet preview end to end; tracked separately.

## Changed

- **Official TangleClaw dark brand palette** (#3133): v6 shell CSS tokens (Venom Green, Viper Emerald, Obsidian Void, Panel Surface, Border Emerald-Slate, Fang Ivory, Muted Sage, Predator Gold), a `100dvh` viewport lock so the header and footer stay pinned without whole-page scrolling, slim 6px dark scrollbars across chat/sidebar/Under the Hood, ~10% tighter Send/Force Send button padding (44px touch-target floor unchanged), and new styling for the Sprint & Cars 6-column board and the collapsible Waiting-On sections.

## Fixed

- **TCC resilience and dir-scanner isolation** (#3130): fixed a blank/frozen `TiLT v2` terminal caused by an untargeted TCC-authorized-server probe opening a stray `[0/0]` copy-mode overlay on the operator's own pane, by keeping a persistent `tc-tcc-anchor` session alive on that server and auto-cancelling any stray overlay before every paste; stopped default-socket tmux calls from silently redirecting to another socket when run from inside one; and stopped a single slow/unresponsive project directory from starving the dashboard scan and dropping every directory listed after it.
- **Sprint & Cars panel fixes** (#3138): fixed the panel's mashed-together text (e.g. `V650-W1-ATC-Lane-DCompleted`) by separating adjacent fields with a literal separator, dropped one of its three duplicate car listings, and corrected gate pills to show pass across all six gates on a car the tracker can confirm was merged rather than just "all issues closed".
