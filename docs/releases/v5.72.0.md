# v5.72.0 — Fleet authority, engine resilience, and release automation

Milestone #59 had zero open and 15 closed issues when this release candidate was cut. The dated [5.72.0] section of `CHANGELOG.md` compiles and consumes 16 accepted fragments.

- A project granted "Fleet Coordinator" authority can now self-service provision its own `<Prefix>-*` sibling projects, and a Project Master granted `write` access auto-enables and mints its own lifecycle API token in the same step (#2937, #2950).
- A crashed or degraded engine now triggers a non-dismissible failover modal (Restart/Swap/Continue/Kill), and a project can delegate scoped wrap/clear authority to another session through an explicit "prepare to wrap"/"prepare to clear" handshake (#109, #1578).
- New safety primitives: an adversarial red-team pass helper, a secure clipboard/secret uploader, a per-project sub-agent-parallelization authorization toggle, and a mechanical PATH guard against a bare `tmux kill-server` taking down the fleet (#108, #1032, #1257, #2946).
- The plan/document viewer and session/dashboard views carry a new TangleClaw watermark and brand kicker, defaulting to 16% opacity and adjustable via `Ctrl+Shift+Up/Down/0`; the README's release banner now updates automatically on every cut (#2928, #2930, #2935).
- Reliability fixes: a macOS TCC false-positive that crashed engine launches on a protected directory, a Linux CI tmux false negative, a slow/stalling `GET /api/projects` under load, and cross-wrapper PATH collisions between the `gh`/`curl`/`tmux` role guards (#2929, #2945, #2948, #2949).
