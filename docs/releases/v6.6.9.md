# v6.6.9 — Fleet sprint visibility and Fleet Shell reliability

TangleClaw v6.6.9 is the release-cut candidate for Wave 2 of milestone #119. The release cut is dated 2026-11-28.

## Fixed

- **Fleet sprint data fallback (#3356):** `GET /api/sprint-waves` and `GET /api/sprint-reports/:version` now parse a fleet's own `LANE_QUEUE.md` car tables when persisted wave-scheduler data is missing for the scope or older than the file's current sprint. Both supported car-table layouts are recognized.
- **Fleet Shell chat/workspace reliability and staggered startup (#3355, #3352):** project-scoped workspace loading no longer races project resolution or applies stale responses; coalesced prompts retain their own chat turns; declarative ternary text and superseded paragraphs no longer trigger false “Waiting on: YOU” prompts; wrapped URLs stop at sentence and punctuation boundaries; and fleet member startups are staggered to avoid concurrent startup flaps. Codex timing recaps, input placeholders, and status-bar footers no longer leak into chat as fake bubbles.
