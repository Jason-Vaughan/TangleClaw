# v6.2.6 — Telemetry and the chat header in one condensed row

TangleClaw v6.2.6 is a fix release on top of v6.2.5, from the operator's live testing of the v6 Project Delegate Chat. In a chat, the telemetry bar and the chat header are now a single condensed row, and the telemetry chips explain themselves. It adds no new routes or settings.

## Fixed

- **One condensed header row** (#3063, tests in `test/v6-b1-ui-shell.test.js` and `test/v6-browser-shell-and-conversation-e2e.test.js`): in a chat, the telemetry pills sit inside the chat header, between the lane's identity strip and the icon buttons, instead of in a separate row above it. Outside a chat, the telemetry bar keeps its own row.
- **Telemetry chips that explain themselves** (#3063): every telemetry chip has a hover tip saying what it measures, its value and how sure the reading is, for example "Active sessions: 23 — live sessions on this TangleClaw server (observed)". In a chat the chips are one-line pills, and a metric with no reading is hidden from sight and from screen readers while staying in the page. Today the server collects only active sessions, health and version, so tokens, the quota window, context use and pending Medusa messages are hidden in a chat until they have a collector.
- **Delegate picker tip** (#3063): the delegate selector's hover tip now reads "Choose who this project's chat talks to — Switch Designated Project Delegate".
