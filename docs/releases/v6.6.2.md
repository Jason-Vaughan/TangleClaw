# v6.6.2 — Interactive choices, per-engine health indicators, V6 chat refinements, and scratch-server reliability

TangleClaw v6.6.2 is the release-cut candidate for the completed four-car Wave 1, plus the STAT P1 scratch-server reliability hotfix merged before this cut. It includes the six v6.6.2 car fragments and the subsequently merged #3315 hotfix fragment. The release cut is dated 2026-11-26.

## Added

- **Interactive choices** (#3259): adds an audited standalone module for recognizing real Claude Code numbered menus, selector dialogs, trust prompts, and multi-choice questions. Live V6 chat wiring remains a follow-up.
- **Per-engine health indicators** (#3269): the engine usage popover shows healthy, degraded, unavailable, or unknown status using each engine's quota-probe reading.

## Fixed

- **Conversation readability** (#3260): improves V6 chat line spacing and breathing room around link previews.
- **Peek Under the Hood filtering** (#3261): the traffic filter now recognizes terminal hard-wrap continuation lines without relying on indentation, and its labels clarify scope.
- **Chat selection stability** (#3287): avoids poll-driven redraws that drop text selection or shift scroll, while deferring full redraws until an active selection clears.
- **Wrapped URLs** (#3291): rejoins a URL split across terminal-wrapped lines without inserting a breaking space.
- **Scratch-server reliability** (#3315): closes EPIPE logging loops, caps/rotates unlinked log descriptors, tears down scratch process groups, and lets orphaned scratch children detect parent loss and exit.
