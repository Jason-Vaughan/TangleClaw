# v6.6.8 — Fleet workspace isolation, full-page settings, and coordinator tools

TangleClaw v6.6.8 is the release-cut candidate for the completed v6.6.8 Wave 1. The release cut is dated 2026-11-28 and targets GitHub Milestone #116.

## Added

- **Full-page settings workspaces (#3346):** Master Settings, project Settings, session Settings, the Group modal, and the OpenClaw connection modal now use full-page layouts. Project Settings organizes its controls into Identity & Paths, Engine & Launch Mode, and Switchboard & Governance categories.
- **Useful defaults for new projects (#3342):** all eight project feature toggles default ON, while explicit values supplied to `POST /api/projects`, including `false`, continue to take precedence.
- **Fleet Coordinator sibling-project authority (#3335):** a verified Fleet Coordinator with an active `project-manager` role can configure sibling projects inside its own fleet namespace, without gaining access to another fleet.

## Fixed

- **V6 workspace fleet isolation (#3345, #3325):** Sprint & Cars, Charter & Roadmap, and Kaizen & Reports now load data for the active project and fleet. Panels refresh when the active project changes, roadmap metadata follows the selected project, and fleet members can see wave runs and Kaizen items recorded by their peers.
- **Staged tc CLI and group-wide Kaizen lookup (#3347):** server startup now idempotently stages the current `tc` CLI sources under `~/.tangleclaw/tc-cli-staged/`; Kaizen list/feed resolution spans the caller's project group.
