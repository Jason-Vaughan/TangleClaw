# v6.6.7 — Global Settings workspace, memory backups, and connection stability

TangleClaw v6.6.7 is the release-cut candidate for the completed v6.6.7 Wave 1. The release cut is dated 2026-11-27.

## Added

- **Scheduled Claude memory backups (#3314):** adds a standalone backup module and CLI for timestamped, SHA-256-manifested snapshots of Claude project correction memory, optional engine memory directories, and optional SQLite databases. Verification precedes restore, with dry-run, project filtering, and retention pruning.
- **Configurable host storage warning threshold (#3318):** adds a Global Settings threshold (default 85%, configurable from 50–98%, or disabled) and reports disk capacity, availability, use, threshold, and status from system health. A fixed 95% critical ceiling remains active regardless of the configured warning threshold.
- **Full-screen Global Settings workspace (#3319):** turns Global Settings into a full-screen workspace with six category sections, cross-category search, deep links, and a Storage & System Health threshold control.

## Fixed

- **Canonical engine hook paths and TCC bootstrap test stability (#3313, #3300):** resolves project hooks against the stable install root, refreshes canonical hook scripts and migrates stale checkout paths, and replaces immediate TCC session-readiness assertions with bounded polling.
- **Browser and ttyd connection stability (#3332):** lengthens ttyd WebSocket pings, configures terminal proxy sockets when the methods are available, caches repeated session and project reads, and adds an opt-in debounce for transient client disconnects.
