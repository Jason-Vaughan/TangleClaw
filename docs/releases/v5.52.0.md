# v5.52.0 — Ingress you can read

This release makes ingress state visible and actionable, and removes two slow dashboard reads. The [release status](v5.52.0-status.md) tracks code publication, the local production update, and live activation separately.

- Caddy Drift detects a widened gate bypass. Its dashboard menu restores the security baseline or acknowledges current findings; new findings show the banner again. Acknowledgment resets after a server restart.
- Global Settings can resolve a Tailscale origin with an explicit reason when it cannot. Plan share links use that origin when enabled. PortHub can reserve a machine-wide Tailscale ingress claim before a session changes the route.
- HEAD follows GET routing and headers without a response body. Warm project facts are cached, project rendering no longer waits for awareness, late awareness replies cannot overwrite newer ones, and usage windows use a bounded pre-warmed snapshot.
- The Stage 5 container includes curl and less, and the profile reconciliation test clock race is removed.

The Caddyfile generator still fronts only TangleClaw's own port; a separate live-file check detects hand-added reach to loopback leases. A second install on one machine remains unsupported. A cold or expired project facts scan retains its prior sequential cost. Session-start and Medusa peer links stay loopback-only by design.
