# v6.2.4 — Chat replies after tool lines, Show Fleet in the chat, a busy timer and project version and branch badges

TangleClaw v6.2.4 is a fix release on top of v6.2.3, from live testing of the v6 Project Delegate Chat. Replies that followed a tool line now appear as bubbles, the Fleet sidebar can always be brought back from the chat, the busy line shows motion and elapsed time, and the chat header shows the target project's own version and branch. It adds no new routes or settings.

## Fixed

- **Replies after a tool line** (#3057, tests in `test/v6-b1-ui-shell.test.js`): Antigravity indents its reply prose by two spaces, and the chat read every indented line after a tool line such as `● Explored …` or `● Ran …` as that tool's output, so the reply never appeared as a bubble. Now, under a tool line, only its `⎿`/`└` output or a line indented four or more spaces counts as output, in every engine. A reply indented by two spaces is kept, even after a blank line, and tool output that contains a blank line still stays hidden.
- **Show Fleet in the chat** (#3057): with the Fleet sidebar hidden, the chat's own action bar offers `» Show Fleet`, and the page header holding the other `» Show Fleet` stays in view while the page scrolls.
- **Busy line with a timer** (#3057): the busy line reads `Working` as soon as a message is sent, until the engine reports what it is doing, a new reply appears, or three reads pass with neither. It shows animated dots in place of static ones, and how long the agent has been working (`0s`, `1m 12s`, `1h 2m`), ticking once a second while busy. It still shows the engine's own activity label, escaped as plain text.
- **Version and branch badges** (#3057, tests in `test/v6-b1-ui-shell.test.js` and `test/v6-browser-shell-and-conversation-e2e.test.js`): the chat header shows the target project's version (or its latest git tag) and git branch, read from its `GET /api/projects` row, because a lane can run a different version or branch from the server in the top bar. A branch with uncommitted changes is starred; an unknown state is not. The chat's Open Hood link is now sized like its neighbouring buttons.
