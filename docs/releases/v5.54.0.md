# v5.54.0 — External code and CI safety

This release candidate reconciles the five closed issues in Milestone #39. The [release status](v5.54.0-status.md) tracks the code merge, tag, GitHub Release, local update, and live verification separately.

- The primary-checkout guard's wired outer runner records genuine invocations and inner-script errors. Self-test exercises refusal and allow paths and checks liveness; status exposes counts and crash or staleness signals (#1400).
- The TangleClaw data directory and existing SQLite sidecars are narrowed to owner-only permissions on boot (#1421).
- Fork-PR test CI no longer persists checkout credentials and has a 20-minute job timeout (#1550).
- External PR text can be sanitized and fenced for review, and a proposed reviewer worker's read-only contract can be checked. The isolated worker is not yet built, so ADR 0014's injection-hold rule remains in force (#1554).
- New per-session usage routes report live context remaining and live Codex weekly quota when available, with a low-usage hand-off signal. Five-hour quotas remain operator-calibrated (#2787).

The dated [5.54.0] section of `CHANGELOG.md` compiles and consumes the five accepted release fragments.
