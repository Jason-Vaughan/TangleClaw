## Release scope and gates

The five accepted `changelog.d/` fragments for #1176, #1196, #1654, #2293, and #2325 were compiled into the dated `[5.51.0]` section and removed. `version.json` is the repository's version source. `scripts/release-prepare.js` updates the README clone pins and extends the released-section lock. This repository has no `package.json` or `package-lock.json`.

Rule delivery on a running Claude session depends on its hook configuration being read after the file-change settle interval; a zero-delay scripted `/clear` is not guaranteed. Engines without a `SessionStart` hook still receive a newly approved rule on next launch or immediately through `tc rules`. Receipt redelivery is bounded and escalates when confirmation remains absent.
