1. Multi-Agent Fleet Architecture & Governance Pipeline

Six specialized roles operating across heterogeneous AI engines (Gemini 4 Argon, Claude Opus 5.5, OpenAI Codex GPT-5.4) with strict file-lock & commit-SHA gates.

🔒 Disjoint Wave File Locking

Before each wave, the Project Manager and Integrator verify candidate paths via git cat-file -e and assign strictly disjoint file sets to Lane A and Lane B. Result: 0 code or test merge conflicts across all 24 waves.

🛡️ Four-Layer Exact-Head Review

Every PR head is verified by the Prawduct Critic, Architect (322 rulings), Observer (32 source-checked reviews), and Integrator, then merged via --match-head-commit so no unreviewed byte can land.

🔄 Governed Continuity & Clears

Builders execute a governed /clear before every PLAN and BUILD step (45/45 first-pass success, <5% context load), while 3 live roles switched engines mid-sprint via generation-bound continuity capsules with 0 dropped exchanges.

5. Sprint Post-Mortem: What Worked vs. What Didn’t

Synthesized by the Project Manager, Architect (Ruling A384), and Sprint Observer across all 24 waves.

✅ What Worked Exceptionally Well (Keep & Codify)

  • 1. Per-Wave W<N>-REC Records Pattern & Exclusive Change-Log Slot Running a dedicated 3-file records PR (CHANGELOG.md, FEATURES.md, .prawduct/change-log.md) at the end of every wave (18 consecutive waves) eliminated cross-lane merge conflicts and allowed W24-REL (PR #2516) to promote [Unreleased] → [5.34.0] (87 bullets, 21,032 B) 100% byte-identically with zero retroactive edits.
  • 2. Systematic Flake Elimination & 10-Chunk #1903 Lift Migration Rather than working around test flakes, the fleet filed, root-caused, and closed every single flake encountered (#2152, #2447, #2481, #2485, #2184, #2504) while migrating 106 inline lift helpers to test/helpers/lift.js, achieving 0 flakes across the final 22 full-suite runs.
  • 3. Governed Builder In-Place /clear Cycles (45/45 First-Pass) Clearing Builder context before every PLAN and BUILD phase kept starting context load at 1%–4.5% across the entire 4-day run, completely preventing long-session instruction drift on Builder lanes.
  • 4. Multi-Layered Exact-Head Pre-Merge Review Critic caught PR #2509’s Caddy cutover trap on /api/setup/complete; Architect caught fail-open Master spawn (PR #2477), symlink clobber (PR #2487), and pre-cut status-doc drift (PR #2516); Observer caught >400 B changelog caps and label omissions; Integrator caught exception-counter bugs (PR #2460).
  • 5. Serializing 2nd-Lane Host Suites Behind 1st-Lane Merge Windows In all 11 dual-lane waves where Lane 2 rebased onto Lane 1’s merged commit before starting its 19-minute host suite, zero green suites were voided by base movement.

⚠️ What Didn’t Work & Proven Fixes for v5.35.0

  • 1. Multi-Compaction Integrator Thread Drift & Unpolled Post-Merge CI (6h 14m Idle) Accepting automatic context compaction at Wave 17/18 instead of an explicit procedural refresh caused the Integrator session to end its turn twice while post-merge main CI was still running (4h 36m in W21, 1h 02m in W22). Fix: Wave 23’s explicit INT-REFRESH re-attestation immediately yielded 0m of stall in Waves 23–24; #1783 adds automatic CI-completion wakes in v5.35.0.
  • 2. Duplicate Host Suites (~170m) & Omitted <3s Static Scanners (~53m) Running both lanes’ 19-minute local suites concurrently on the same base (Waves 1–2, 9–11) or re-running a 19-minute suite for a 2-line prose tweak (PR #2514), plus omitting fast repo scanners (auto-merge-callers, tmux-session-names, wrap-indicator-card) from pre-suite narrow rings. Fix: Ship #2371 (CI-as-suite evidence), #2498 (5-Stage S/M/L Test Pyramid), and mandatory <3s static pre-suite rings.
  • 3. Premature work-blocked Alerts (#2141) & JUnit Subtest Blind Spot (#2456) bridge-notify.js paged Discord within 6–9s when a Builder waited 4–13m for a routine coordinator ruling, with no work-unblocked clearance notice; and top-level JUnit parsing missed nested subtest failures when node --test exited rc=1. Fix: Scheduled in Waves 2 & 4 of v5.35.0.
  • 4. Rebase-Merge Commit-Message Auto-Close Checks & Launch-Dirty Finalize gh pr merge --rebase ignores Fixes #N when only in the PR body or triggers on intermediate branch commits (#2313); and tc finalize refused on a file that was dirty at launch but merged to main in Wave 1. Fix: Pre-merge commit-log regex check + clean-HEAD launch-dirty reconciliation in v5.35.0.
