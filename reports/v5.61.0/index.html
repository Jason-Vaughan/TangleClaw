What Didn't Work & Concrete Guardrail Fixes Enacted in v5.61.0

1. Symlink & Non-Regular File Target Risk on `.tangleclaw/lane-queue.json` Bootstrap (#2869 Round 2)

In `Car 61-B` (`PR #2869`), initial fleet provisioning bootstrap logic checked whether `.tangleclaw/lane-queue.json` existed before writing, which could follow a dangling symlink or fail on a directory at that path. Fix / Guardrail: Updated `lib/fleet-provisioning.js` (`1946335d`, `40884a9f`) to inspect `lstat` and explicitly refuse symlinked or non-regular file targets before bootstrapping queue state.

2. Persisted-vs-Observed Listener Drift in Master Authority Lifecycle Repair (#2868 Round 2)

In `Car 61-C` (`PR #2868`), checking only persisted configuration missed cases where persisted settings reported Master Authority enabled while the live runtime listener was actually off. Fix / Guardrail: Updated `lib/master-authority.js` (`71c1f4ea`) so drift diagnostics compare persisted authority configuration against the observed runtime listener state.

3. Caller-Supplied vs. Authoritative Impact in `decideWorkspaceRename` (#2863 Round 2)

In `Car 61-D` (`PR #2863`), allowing callers to pass pre-computed impact objects into `decideWorkspaceRename` risked stale orphan-state evaluations. Fix / Guardrail: Updated `lib/workspace-rename-check.js` (`ac71936c`) so `decideWorkspaceRename` always computes its own authoritative active-session and orphan impact at decision time.

4. Recognizing Short Flag Aliases (`gh pr merge -m/-s/-r`) in Merge Role Guard (#2865 Round 2)

In `Car 61-A` (`PR #2865`), initial command matching in `lib/merge-role-guard.js` needed to cover short flag aliases and flag reorderings on `gh pr merge` as well as distinguishing `"read"` from `"resolved"` in bridge notifications. Fix / Guardrail: Hardened `lib/merge-role-guard.js` and `lib/bridge-notify.js` (`0faf99a9`) with comprehensive alias parsing and regression tests.
