📖 Plain-English Summary — What Sprint v5.48.1 Accomplished & Why It Matters Written for operators, stakeholders & non-specialist readers

Moving TangleClaw’s Heavy Test Suites Off the Main Mac & Hardening Agent Messaging

Until now, every time an AI coding agent finished a change in TangleClaw, our primary server machine (cursatory) had to run thousands of automated tests locally—tying up CPU cores for 14 minutes at a time and forcing other agents to wait in line. Sprint v5.48.1 connected TangleClaw to Testament v0.30.0, a distributed cluster of 4 remote computers providing 66 parallel test slots, while also fixing two subtle bugs that could leave AI agents unreachable after a temporary model outage or a session restart:

1. 27-Second Remote Test Offload (`#2733` + `#2706`)

Instead of bogging down our main machine, TangleClaw now ships a tiny 58.6 KB change bundle over an encrypted connection to 4 remote machines (gpu-bozeman, nas-bozeman, 14th-mbp, and laptop). Our 253-file Small test suite (5,836 tests) now finishes in just 27.1 seconds using 0% CPU on our main server—and if the remote pool is ever offline, TangleClaw automatically falls back to running tests locally without failing. We also tuned our slowest test timeout from 60 minutes down to a realistic 25 minutes (#2706).

2. Self-Healing Agent Wakes & Replies (`#2723` + `#2726`)

Previously, if OpenAI’s Codex service hit a brief capacity hiccup (reporting systemError), TangleClaw thought the agent was still busy and refused to send it wake-up nudges; TangleClaw now recognizes that the agent is resting and wakes it normally (#2723). Likewise, when a message is automatically rerouted from an old agent session to its replacement, the recipient can now reply directly without hitting an “unknown reply target” error (#2726).

3. Smarter Builder Workflow for v5.49.0+ (`Rule #294` + `P44`)

By bundling 2 related issues into each Builder’s pull request (Rule #294), we cut pull-request overhead in half and eliminated mid-sprint session restarts. Even better, the Operator spotted that our Claude Builders were still running an old internal self-review loop (/prawduct:critic) that burned 4–7 minutes and ~136,000 tokens per round duplicating our dedicated Codex reviewers—removing that in v5.49.0 will make every future sprint dramatically faster and cheaper.
